# 管理员侧与运营后台设计

> 约束范围：本册约束舰桥（`web/`，原生 HTML+JS）作为治理与调试面的定位纪律、导航边界与已移除面板口径、互通治理的后端 only 现实、以及前端确认与后端鉴权的责任分界。舰桥各面板的接口依赖与操作手册见 `../技术说明书/10-运维、排障与验收.md` 与使用说明书运维章节，本册不复述。

## 1. 定位不变量：治理与调试面

舰桥随舰体提供（server 挂载 `web/` 静态目录，无构建步骤），面向管理员。设计基调固定为**密集、可扫描、可定位问题**：

| 要求 | 含义 |
| --- | --- |
| 状态显式 | 每个面板给出运行态、错误反馈与确认边界，不给单一「运行中」糊弄态 |
| 分页限量 | 表格、日志、监控面板必须分页/筛选/限量，禁止一次渲染大量 DOM（内存与吞吐都是事故源） |
| 高风险默认 | 治理操作默认高危：确认流、权限校验、审计落点缺一不可 |
| 反营销化 | 不做营销布局与情绪化装饰；信息密度优先 |

**前端确认不能替代后端鉴权**：舰桥的确认弹窗只是操作纪律的第一层；执法在后端（管理门校验与逐 handler 归属检查，见 `12-安全-权限与隔离设计.md`）。任何「前端已确认所以后端可放行」的设计评审结论无效。

## 2. 装配架构（边界）

| 机制 | 位置 | 规则 |
| --- | --- | --- |
| 面板装配 | `web/app.js` `panelMap`（:156 起） | panel ↔ nav 一一对应；`app.js` 只做启动、导航与模块装配，不再堆业务 |
| 工具管理聚合 | `app.js:196` `TOOL_MANAGER_PANELS` | builtin / mcp / knowledge / skills / toolVisibility 五个面板归同一「工具管理」导航入口 |
| 领域模块 | `web/modules/`（41 个文件） | 新增业务逻辑落领域模块，各自导出 `initXxxPanel/loadXxx`；样式按域拆在 `web/styles/`；共享小工具在 `web/shared/` |
| 统一 DOM 收集 | `modules/elements.js` | 面板 DOM 引用集中收集，不在模块里散落 `getElementById` |

## 3. 当前导航边界（4 组，实测 18 项）

| 组 | 项 |
| --- | --- |
| 系统 | 内部状态、系统设置、单位管理、用户管理 |
| 智能体 | 模型配置、线程管理、预设智能体、形象管理、工具管理（聚合 5 面板）、系统提示词 |
| 调试 | 吞吐量测试、性能测试、能力评估、多模调试、调试面板、LSP |
| 文档 | 使用说明书、接口 |

**已移除面板**（`web/modules/` 中对应模块文件已不存在，文档不得再描述）：云端接入、互通舰队、外链管理、渠道监控、A2A 服务、自建工具（user-tools）。渠道与定时任务在舰桥仅作为「预设智能体」内的模板页存在，没有独立的用户级管理面板；舰桥没有长期记忆面板、没有 goal UI。

## 4. 互通治理：当前后端 only（如实边界）

互通的舰队、通道、命令台账、审计与策略治理**只有后端 API**（`api/admin_interlink.rs`），没有舰桥前端——`web/modules/` 无 interlink 面板，`web/` 全目录仅 `state.js:26` 残留 `panelLoaded.interlink` 标志（死条目，已实测）。写「舰桥互通治理面板」即为幻觉。互通的协议与风险分层设计见 `07-接入、网关与渠道系统设计.md` 第 4 节；治理面前端的补齐是待办，不是现状。

## 6. 运营价值判据

一个合格的治理面要能让管理员快速回答：谁在线、哪个线程卡在哪一轮、哪个渠道/网关连接异常、哪个 agent 配置错误、这次故障属于 prompt / 工具 / 存储 / 实时链路的哪一段。出口分别是 presence 管理面、线程管理与轨迹、渠道运行日志、智能体与模型配置、监控与工具日志。监控口径必须与后端真相一致（如 token 统计在监控 payload 内、上下文占用只取观测 input），不允许前端私有推导。

## 7. 验收判据

- 新增面板必须走 `panelMap` 装配并落 `web/modules/` 领域文件，不向 `app.js` 堆业务。
- 任何列表出口在后端与前端都有分页/限量；用超量数据负向验证不卡死 DOM。
- 治理动作有后端鉴权兜底：绕过舰桥直接调 API，权限结果与舰桥展示一致（前端确认不构成放行路径）。
- 文档与本册导航边界一致：已移除面板与幽灵文案不出现在「现有能力」清单。
