# 蛹“眺望心舰”3D 展示支持方案

## 目标

在蛹（本地 AI 工作台）的系统设置中增加“眺望心舰”入口，展示与舰桥相同的心舰模型。模型、默认取景、材质颜色和基本交互以舰桥当前 `wunder.glb` 查看器为基准，同时满足蛹对 Win7、Ubuntu18.04、离线运行、低内存和软件渲染的约束。

## 现状与约束

舰桥使用 Three.js 加载 `web/third/models/wunder.glb`，模型为 GLB，包含 18 个网格、3 个材质、约 26.9 万顶点和 31.3 万三角形，无外置纹理图片，主要依赖顶点颜色和材质参数。舰桥使用透视相机、环境光、主光、轮廓光、自动旋转、轨道式旋转/缩放/平移和完整取景。

蛹前端是 Rust + Slint，软件渲染是 Win7/Ubuntu18.04 的共同基线。`D:\proj\rcho\frontend-slint` 的成熟经验表明，3D 能力应由 Rust 后台生成有界 RGBA 帧，Slint 只负责布局和投影；在 Win32/X11 上可以再接入原生子画布，其他平台保留 Slint `Image` 回退。

## 分层设计

### 设置页

在 `frontend-slint/ui/settings_page.slint` 增加稳定 tab id `11` 的“眺望心舰”分类，页面使用独立的全尺寸画布，不套普通设置卡片。导航搜索、分类计数、预览模式和 smoke 测试统一增加该分类。

页面支持：

- 左键拖动旋转；
- 右键拖动平移；
- 滚轮缩放；
- 双击或复位按钮回到舰桥默认视角；
- 自动旋转/暂停；
- 加载中、加载失败、重试和渲染不可用状态；
- 设置页关闭或窗口隐藏时停止动画和后台渲染。

### Rust 模型层

新增 `frontend-slint/src/native/wunder_model/`：

- `glb.rs`：解析 GLB JSON/BIN chunk、节点层级、glTF 矩阵/TRS、顶点位置/法线/顶点色、索引和 PBR base color，并完成居中和最大边归一化；
- `raster.rs`：实现透视投影、深度缓冲、双面三角形光栅化和基于 PBR 金属度/粗糙度的近似光照；
- `mod.rs`：维护视角状态、自动旋转、可见性门控和单任务调度，后台只保留一个运行中的渲染任务，新的视角覆盖待处理请求。

模型场景在首次使用时解析一次并缓存；每次渲染只创建视口大小的颜色/深度缓冲。资产放在 `frontend-slint/assets/models/wunder.glb`，由构建产物内嵌，蛹不依赖舰桥目录、本机 HTTP 或运行时网络。

### 帧交付

渲染任务在后台线程运行，UI 线程只提交最新帧和状态；帧尺寸限制在窗口物理尺寸并设置上限，避免无界内存。Win32/X11 优先走原生子画布，其他平台继续使用 Slint `Image` 回退。

当前已抽出 `frontend-slint/src/native/presenter/`，按 `rcho` 的成熟实现提供 `ModelPresenter`：Windows 使用持久 32 位 top-down DIB + `StretchDIBits` 子窗口，Linux/X11 使用 XImage 子窗口和受限事件泵；不满足条件时继续使用 Slint `Image` 回退。presenter 只接收已完成的 RGBA 帧，不参与模型解析和相机计算，窗口几何与帧尺寸分离，避免缩放期间重复上传和黑帧。

## 取景与视觉对齐

- 透视 FOV 使用 36°；
- 模型按舰桥 `Box3` 结果居中，最大边归一化到 4；
- 默认相机位置对齐舰桥 `(0.02, -4.88, 0.01)`，蛹光栅器使用对应的 `yaw=180.235°`、`pitch=-0.117°`、距离 `4.88`；
- 默认显示完整模型并保留少量边距；
- 自动旋转速度与舰桥保持同量级；
- 背景使用舰桥 CSS 的径向渐变（中心 `#fff`，75% 处过渡到 `#edf2f7`）；
- 材质使用 GLB 中的 base color、顶点色、法线、metallicFactor 和 roughnessFactor，软件光栅器使用稳定的漫反射和高光近似；
- 不做网格简化、不重建几何，优先保持 1:1 轮廓。

## 性能边界

- 同时最多一个渲染任务；
- 拖动输入按约 16–33 ms 合并；
- 拖动期间保持完整视口分辨率，只合并最新视角请求，松手约 100–120 ms 后补一帧当前视角；
- 自动旋转和页面隐藏遵循可见性门控；
- 场景解析和三角形准备只做一次；
- 不复制聊天历史或设置页其他模型数据；
- 所有像素缓冲按视口上限分配，退出页面及时释放。

## 验证

- `slint-viewer --check` 编译主界面；
- `slint-viewer --screenshot` 检查设置页和“眺望心舰”布局；
- GLB 解析测试锁定网格、顶点、三角形和材质数量；
- 相机复位、旋转、缩放、平移和调度器测试；
- Win7 与 Ubuntu18.04 X11 真机验证启动、交互、窗口缩放、资源释放和帧耗时；
- 与舰桥默认视角截图对比轮廓、颜色和完整取景。

## 实施顺序

1. 统一设置分类数组和搜索映射，增加 tab `11`；
2. 内嵌 GLB 资产并实现解析、场景、相机、光照和 CPU 光栅化；
3. 接入 Slint 设置页、状态和手势；
4. 增加后台调度、预览/完整帧和资源释放；
5. 运行 Slint Viewer、Rust 测试和蛹真机验收；
6. 在 Win32/X11 真机检查原生子画布的窗口生命周期、缩放和 expose 重绘；不支持原生子窗口的平台保持回退路径。
