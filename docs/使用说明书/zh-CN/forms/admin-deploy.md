# 管理端部署

## 部署

- **入口**：随服务端启动，浏览器访问 `http://<host>:18000/`，端口与服务端一致（默认 18000）。
- **前提**：与云端版共用同一次服务端部署，见[云端版的部署](cloud-deploy.md)。
- **登录**：用管理员账号进入；单位负责人只能管理本单位的单位与用户账号。首次登录后立即修改默认口令。
- 同一端口还提供 API（`/wunder/*`）、MCP 服务端与外部工作流入口。
