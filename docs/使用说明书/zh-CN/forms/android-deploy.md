# 安卓版部署

## 部署

- **系统**：Android 8.0（API 26）起；arm64-v8a（x86_64 切片只用于模拟器验证）。
- **安装**：下载 `wunder-android-*-arm64.apk` 安装后打开即可，没有端口、没有必需参数，数据保存在手机上。
- **运行环境**：默认内置 Ubuntu 运行环境（arm64），命令、文件与工具能力在手机上同样可用。
