# 桌面版使用

## 使用

### 第一次启动

1. 启动页结束、工作目录与会话就绪后进入工作台。
2. **设置 → 模型 → 添加**：填 API Key、接口地址（形如 `https://example.com/v1`）、模型名与参数，保存前点「测试连接」。
3. **设置 → 账号**：填用户名、邮箱、头像；长期使用请设置登录密码。
4. 回对话页输入「帮我列出当前工作目录的文件」，看到思考 → 工具批次 → 最终回复就说明跑通了。

### 执行过程

- 每轮回复下方的「工作过程」把中间思考、工具批次与中间打印折叠起来。
- 一次执行按用户轮次 / 模型轮次展示，细节见[会话与轮次](/docs/zh-CN/concepts/sessions-and-rounds/)。
- 运行中再发消息会排在输入框上方，当前轮次结束后自动发出，不会被打回。

### 常用入口

| 想做的事 | 去哪 |
| --- | --- |
| 跑命令 | 对话页的终端视图（Windows 用 winpty，Linux 用 PTY） |
| 换模型 / 调思考等级 | 输入区 |
| 管 MCP 服务 / 技能 | 设置 → MCP 服务 / 技能 |
| 看某条线程怎么跑的 | 线程轨迹 |
| 定时巡检、周期提醒 | 设置 → 定时任务 |
| 长期记忆条目 | 设置 → 记忆碎片 |
| 渠道账号与日志 | 设置 → 渠道设置 |

### 快捷键

截图快捷键只在工作台窗口有焦点时生效，不会占用其它软件的 `F1` / `F2`：

| 键 | 作用 |
| --- | --- |
| `F1` | 先隐藏工作台窗口，再弹区域截图选区，截的是窗口背后的内容 |
| `F2` | 保留工作台窗口，直接弹区域截图选区 |

确认选区后图片回填输入区，桌面版同时复制到系统剪贴板。托盘菜单与输入区「+」里的「截图」等价于 `F1`。

选区不是一次性的：松开后仍可拖动选区内部移动位置，拖动四角与四边的八个控制点缩放；方向键每次移动 1 像素，按住 `Shift` 移动 10 像素，`Enter` 确认，`Esc` 或右键取消。移动指针不会再持续描边；需要自动吸附时按 `空格`，以当前指针位置（打开选区时的真实光标位置）吸附窗口，再由 UI Automation 在后台细化到按钮、标签页、列表项等控件。检测只在按键时执行，打开选区本身不枚举窗口或探测控件；同一帧内再次按 `空格` 可按新位置重新检测，识别不到控件时保留窗口矩形。`F1` 隐藏窗口后直接抓帧并复检画面，不再固定等待，进入选区的速度与 `F2` 一致。

## 独有能力

以下能力云端版、管理端与命令行上都没有：

- **交互式终端**：可以像在终端里一样敲命令。
- **托盘与系统通知**：后台运行、任务完成时提醒。
- **全局热键**：用系统快捷键唤起。
- **截图采集**：`F1` 先隐藏窗口再区域截图，`F2` 保留窗口截图；区域或全屏截图回填到输入区，桌面版同时复制到系统剪贴板，可直接粘贴到其他软件。
- **语音输入**：用麦克风说话转成文字。
- **本地文件与桌面控制**：直接读写本机文件、操作桌面（桌面控制需要视觉模型）。

## 边界

- **没有「设备互通」设置面板**：设置页 11 个分类里不含互通；能用的互通只有侧栏「工作目录」里的云端工作区，以及远端命令审批弹窗。
- **不能播放语音（TTS）**：语音输入可用，设置里也能配 TTS 模型，但没有播放；要听语音输出请用[云端版](/docs/zh-CN/forms/cloud-ui/)。
- **重置工作状态没有界面入口**：调用 `POST /wunder/auth/me/reset_work_state`，它会停止运行中的会话、清空排队任务、清理会话锁，保留技能、知识库、长期记忆、配置与会话历史。
- **另有一个兼容端口**（默认 18123），只给少数既有客户端用，日常使用不涉及。
- **智能选区按需触发**：按 `空格` 才做窗口/控件识别；首次按键懒加载窗口树，随后由 UI Automation 细化。自绘或未开启无障碍的应用可能只识别到窗口级；跨进程探测超时或失败时保留窗口矩形，不影响继续拖动和确认。
