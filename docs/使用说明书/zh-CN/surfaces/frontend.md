# 蜂巢界面

蜂巢是 wunder 的**云端 AI 工作台**：部署好舰体之后，成员用浏览器打开就能用。它本身没有独立进程，页面跟着舰体一起提供。

## 打开与登录

用浏览器访问舰体地址，未登录会跳到登录页，也可以直接注册。登录后默认进入你的智能体对话页。

- **对话**：主工作区，见「主区」一节
- **嵌入式对话**：可以把对话嵌到别的页面里使用
- **外部工作流落地页**：通过链接进入的外部流程页面
- **设置**：进入后仍停在对话页，右侧切到对应的设置分类
- **线程轨迹**：查看整条线程的执行记录
- **管理后台**：管理员登录后另有用户、智能体、系统等管理页

## 主区

蜂巢的主区是一个三栏的对话工作区：

- **左栏**：新任务、搜索、工作区与线程树、工作目录、设置入口
- **右栏**：聊天顶栏 + 时间线 + 输入区
- **浮层**：文件预览、在线编辑、形象浮层

一个智能体可以同时拥有多个独立任务线程；工作区可以有多份：你自己的云端工作区，以及通过设备互通访问的远程设备工作区。

## 实时更新与连接

对话的实时状态走一条长连接：新消息、执行进度、审批提示都靠它推过来。断线重连后，会通过普通请求把状态补齐，不需要重开页面。

如果网络或代理把这条长连接拦了，实时状态就不更新，刷新页面通常能恢复。

## 长对话的渲染

时间线不会把整条线程一次性铺出来，而是按窗口加载、滚到哪加载哪，长线程打开时不至于卡住；解析和渲染也放到后台线程里做，不占用主线程。

超大数据量线程的渲染优化方案目前只是一版重写，业务实现还没完全落地，超长线程仍可能卡顿。

## 设置分类

蜂巢的设置以分类挂在对话页里，和蛹共用同一套后端能力。包含：

- **通用 / 账户 / 模型 / 智能体 / 形象 / 提示词包 / 帮助**（和蛹一样）
- **工具**：分内置 / MCP / 技能 / 知识库四个标签页
- **记忆**：长期记忆管理
- **渠道**：渠道绑定与状态
- **定时**：定时任务
- **设备**：设备互通管理入口
- **归档**：归档线程

## 与蛹的差异

| 项 | 蜂巢 | 蛹 |
| --- | --- | --- |
| 运行方式 | 浏览器访问云端 | 装在自己电脑上的桌面应用 |
| 数据存放 | 舰体存储 | 本地 |
| 交互式终端 | ❌ 无 | ✅ 有 |
| 语音输入 / 输出 | 双向 ✅ | 输入 ✅，输出 ❌ |
| 设备互通 | ✅ 设置设备分类 + 互通视图 | ⚠️ 仅云端工作区 + 审批弹窗；设置分类未开放 |
| 托盘 / 系统通知 / 全局热键 / 截图 | ❌ | ✅ |
| 附件上传上限 | 临时附件 200 MB，持久附件 10 MB | 本地文件直接引用 |

## 输入区要点

- **消息输入**：自然语言，也可以输入斜杠命令
- **附件**：本地选择或拖拽
- **发送 / 停止**：没在运行时发送，运行中变成停止
- **模型切换**：直接在输入区切换，不用跳设置页
- **审批模式**：建议 / 自动编辑 / 完全自动（默认完全自动）
- **思考等级**：底部脑图标，灰色表示跟随模型，空 / 半满 / 全满分别表示无思考 / 中等 / 最高
- **工作线程面板**：和工作目录共用同一个外层面板；标题右侧常驻状态图标和活动数量；筛选按钮在没有活动后仍保留，可以随时退出筛选；筛选期间仍能拖拽排序

## 时间线与状态

- 每轮回复下方的「工作过程」把中间思考、工具批次、中间打印折叠起来
- 状态：🔄 运行中 / ⏳ 等待（需要你输入或审批）/ ✅ 已完成
- 上下文占用和耗时对应发起该工具的那次模型请求；同一次请求里并行跑的工具共享同一组数字，不逐条相加
- 很快的调用可能显示 `0ms`；失败和取消也会记录耗时

## 斜杠命令

在消息输入框里输入：

- `/new` 新建线程
- `/stop` 停止当前执行
- `/compact` 主动压缩对话
- `/help` 打开帮助文档
- `/goal` 目标管理

`/compact` 也算一次用户轮次；压缩后的摘要直接显示在命令后面的回复气泡里，切换线程或刷新页面后仍在。

## 保护机制

- **附件处理中**：发送按钮会被禁用，等处理完再发
- **后台运行**：切换、新建、刷新或短暂离线，都不会取消正在跑的工作线程；重新连上后从已保存的事件恢复状态和待审批项
- **空线程复用**：新建线程会优先复用当前智能体还没用过的空线程；已经发过消息、正在运行或由子智能体派生的线程不会被复用
- **删除同步**：管理员删掉线程后，你这边会在列表刷新或切换时清理掉条目和缓存；点到失效条目会有提示并回到输入页

## 常见问题

**蜂巢与舰桥是两套界面**：蜂巢面向使用者，舰桥面向管理员，两套界面分开。

**蜂巢支持多人共用**：蜂巢本身就是团队 / 多用户场景，成员用舰体账号登录。个人单机推荐蛹。

**蜂巢没有终端**：需要 shell 时用蛹或舵机。

**语音输出（TTS）可用**：蜂巢支持双向语音（含 TTS）；蛹只有输入，没有播放。

**设备互通用法**：蜂巢是完整入口，设置在「设备」分类里，命令审批在时间线里内联弹出。
