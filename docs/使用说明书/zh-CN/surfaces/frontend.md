# 蜂巢界面

打开 wunder 后，日常的对话、文件读写和设置都在蜂巢完成。个人用户通过[蜂窝](/docs/zh-CN/start/desktop/)打开它，团队成员用浏览器访问蜂巢（web）。

## 左右两栏

```
┌──────────────┬─────────────────────────────────────┐
│  Sidebar     │  聊天顶栏（工作区名 / 线程名）        │
│  (240px)     ├─────────────────────────────────────┤
│  新任务       │                                     │
│  搜索         │  时间线                              │
│  ─ 工作区 ─   │                                     │
│   线程 A      │                                     │
│   线程 B      ├─────────────────────────────────────┤
│  ─ 工作目录 ─ │  输入区（模型切换 / 发送）            │
│  文件树       │                                     │
│  用量条       │                                     │
│  设置         │  状态栏                              │
└──────────────┴─────────────────────────────────────┘
```

- **左栏**（固定 240px）：新任务按钮、搜索框、工作区与线程树、**工作目录区**（文件树 + 工具栏 + 用量条）、底部设置入口
- **右栏**（自适应）：未选中线程时是欢迎页，选中线程后是聊天页（顶栏 + 时间线 + 输入区）

左栏上下两个区各自独立滚动，中间的分隔条可以拖动；窄屏时左栏转为抽屉式浮层。

## 聊天

### 输入区

输入区用于发起任务、补充上下文和控制当前线程。常用方式包括：

| 区域 | 作用 |
|------|------|
| **消息输入** | 输入自然语言任务、问题或斜杠命令 |
| **附件入口** | 选择本地文件或拖拽文件，处理完成后随消息发送 |
| **发送/停止** | 未运行时发送消息，运行中用于停止当前执行 |
| **模型切换** | 在输入区直接切换当前使用的模型，不用跳到设置页 |
| **审批模式** | 选择工具执行前的审批严格程度（云端安全边界） |
| **思考等级** | 大脑图标从底部填入橙色：无思考为空、中等为半满、最高为全满；默认跟随模型时保持灰色，不表示实际思考预算 |
| **工作线程** | 每个运行条目有轻量动画；可切换或新建其他工作线程，原线程会在后台持续运行 |

蜂巢工作线程面板采用与工作目录一致的外层面板和内层列表。标题右侧常驻状态图标与活动数量，无活动线程时显示灰色空闲图标和 0；点击只显示运行中、排队或等待交互的线程，再点恢复全部线程及原来的滚动位置。活动全部结束后，筛选按钮仍保留，可随时退出筛选。筛选期间仍可拖拽调整顺序。

如果任务需要读写已有文件，先把文件放到左栏的工作目录区，再在消息里说明相对路径或文件名；也可以用文件行菜单的「引用到聊天」直接带进输入区。

### 上下文与工具耗时

输入区的“已占用/容量”显示最近一次模型请求的输入 Token。生成内容流式输出时保持最近确认值，下一次请求观测后更新；压缩后允许下降或归零，短暂缺少统计不会闪空。

智能体循环中的上下文和 Token 消耗对应发起该工具的那次模型请求。同次请求的多个并行工具共享这些数字，无需逐条相加。耗时表示本次工具处理用时（包含处理期间的审批等待）；极快完成的调用可显示 `0ms`，失败或取消也会记录耗时。

### 斜杠命令

| 命令 | 作用 |
|------|------|
| `/new` | 创建新线程 |
| `/stop` | 停止当前执行 |
| `/compact` | 主动压缩对话 |
| `/help` | 打开帮助文档 |

`/compact` 也算一次用户轮次。压缩摘要会直接显示在命令后的智能体气泡中，压缩过程可在智能体循环中查看，不另加分隔线。完成后切换线程或刷新页面会保留摘要和完成状态。

### 保护机制

- **附件处理中**：发送按钮禁用，等处理完再发
- **后台运行**：切换、新建、刷新或暂时离线不会取消已有工作线程；重新打开后会从持久化事件恢复状态和待处理审批
- **空线程复用**：点击「新建线程」优先打开当前智能体已有的未使用空线程，切换到其他线程后再次点击也会复用它，避免重复堆积新会话。已发送消息、正在运行或子智能体派生的线程不会作为空线程复用。
- **删除同步**：管理员删除线程后，用户端会在后续列表刷新或切换时清理对应条目和缓存，无需手动清除浏览器数据。如果点击了尚未刷新的失效条目，页面会提示并回到该智能体的输入页，不会留下无法打开的线程。

### 自动重试状态

模型生成的工具调用格式错误或没有返回有效内容时，消息下方会显示对应原因、尝试次数和等待时间。自动恢复期间仍可停止任务；恢复成功后继续显示正常进度，最终失败或停止后不再持续加载。刷新或重新进入线程后，也能恢复已记录的重试状态。

## 工作目录

左栏工作区下方的「工作目录」区展示属于你的唯一工作区（蜂窝里是本机持久目录，蜂巢里是服务端用户目录）。你可以：

- 浏览目录结构（目录懒加载展开）
- 上传、下载、删除、重命名、移动、复制文件
- 预览文本、图片、PDF、Office 文档与流程图
- 多选后批量删除或打包下载
- 用文件行菜单的「引用到聊天」把文件带进输入区
- 在区域底部看到已用容量与文件数

## 智能体设置

每个用户只有一个智能体实例，由管理侧预设 1:1 绑定生成。用户侧没有创建、删除、切换或排序智能体的入口。在左栏底部的「设置」里可以：

- 查看当前智能体实例与绑定的预设
- 修改预设允许自定义的字段（如默认模型、审批模式、工具集合）
- 配置提示词模板与技能
- 添加专属记忆
- 该智能体可以拥有多个独立线程

预设未开放自定义的字段会显示「由管理员预设」并保持只读。

## 工具与技能

- 查看可用工具列表（用户侧只读与开关，工具清单由管理侧维护）
- 配置技能（能力包）
- 添加知识库，让智能体参考你的专属资料

## 定时任务

- 创建定时执行的任务
- 查看执行历史
- 管理、暂停、删除任务
- 手动触发一次执行

## 我的概况与设置

### 我的概况

- 头像、用户名、等级
- 经验进度条
- 使用统计（会话数、工具调用数、Token 消耗）
- 额度账户余额和趋势

### 账户管理

- 修改用户名、邮箱、密码
- 查看所属单位

### 系统设置

- 界面语言切换
- 一键重置工作状态（异常恢复）

### 帮助手册

- 内嵌文档入口，不离开工作台即可查阅

## 状态识别

注意界面上的状态指示：

- 🔄 运行中 = 正在执行
- ⏳ 等待中 = 需要用户输入或审批
- ✅ 已完成 = 可以继续
