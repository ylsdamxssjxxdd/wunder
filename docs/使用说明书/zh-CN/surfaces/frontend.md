# 蜂巢界面

蜂巢是用户的工作台。对话、管理文件、配置智能体、使用工具——都在这里完成。个人用户通过[桌面端](/docs/zh-CN/start/desktop/)打开，团队成员通过浏览器访问网页端，界面与能力一致。

## 三栏布局

- **左栏**：导航入口（聊天、文件、智能体、工具、定时任务、设置、帮助）
- **中栏**：列表区（会话列表、文件列表、智能体列表等）
- **右栏**：工作区（对话、文件预览、设置面板等）

## 聊天

### 输入区

输入区用于发起任务、补充上下文和控制当前线程。常用方式包括：

| 区域 | 作用 |
|------|------|
| **消息输入** | 输入自然语言任务、问题或斜杠命令 |
| **附件入口** | 选择本地文件或拖拽文件，处理完成后随消息发送 |
| **发送/停止** | 未运行时发送消息，运行中用于停止当前执行 |
| **思考等级** | 大脑图标从底部填入橙色：无思考为空、中等为半满、最高为全满；默认跟随模型时保持灰色，不表示实际思考预算 |
| **工作线程** | 每个运行条目有轻量动画；可切换或新建其他工作线程，原线程会在后台持续运行 |

网页端工作线程面板采用与工作目录一致的外层容器和内层列表。标题右侧常驻状态图标与活动数量，无活动线程时显示灰色空闲图标和 0；点击只显示运行中、排队或等待交互的线程，再点恢复全部线程及原来的滚动位置。活动全部结束后，筛选按钮仍保留，可随时退出筛选；切换智能体会恢复全部线程。筛选期间仍可拖拽调整顺序。

如果任务需要读写已有文件，优先把文件放到当前智能体的工作目录，再在消息里说明要使用的路径或文件名。

### 上下文与工具耗时

输入区的“已占用/容量”显示最近一次模型请求的输入 Token。生成内容流式输出时保持最近确认值，下一次请求观测后更新；压缩后允许下降或归零，短暂缺少统计不会闪空。

智能体循环中的上下文和 Token 消耗对应发起该工具的那次模型请求。同次请求的多个并行工具共享这些数字，无需逐条相加。耗时表示本次工具处理用时（包含处理期间的审批等待）；极快完成的调用可显示 `0ms`，失败或取消也会记录耗时。

### 斜杠命令

| 命令 | 作用 |
|------|------|
| `/new` | 创建新线程 |
| `/stop` | 停止当前执行 |
| `/compact` | 主动压缩对话 |
| `/help` | 打开帮助文档 |

`/compact` 也算一次用户轮次。压缩摘要会直接显示在命令后的智能体气泡中，压缩过程可在智能体循环中查看，不另加分隔线。完成后切换线程或刷新页面会保留摘要和完成状态。

### 保护机制

- **附件处理中**：发送按钮禁用，等处理完再发
- **后台运行**：切换、新建、刷新或暂时离线不会取消已有工作线程；重新打开后会从持久化事件恢复状态和待处理审批
- **空线程复用**：点击「新建线程」优先打开当前智能体已有的未使用空线程，切换到其他线程后再次点击也会复用它，避免重复堆积新会话。已发送消息、正在运行或子智能体派生的线程不会作为空线程复用。
- **删除同步**：管理员删除线程后，用户端会在后续列表刷新或切换时清理对应条目和缓存，无需手动清除浏览器数据。如果点击了尚未刷新的失效条目，页面会提示并回到该智能体的输入页，不会留下无法打开的线程。
- **编排态中**：编排线程在普通聊天页只读，需回编排页操作

### 自动重试状态

模型生成的工具调用格式错误或没有返回有效内容时，消息下方会显示对应原因、尝试次数和等待时间。自动恢复期间仍可停止任务；恢复成功后继续显示正常进度，最终失败或停止后不再持续加载。刷新或重新进入线程后，也能恢复已记录的重试状态。

## 编排工作台

编排页适合需要持续推进的蜂群任务：

- 母蜂持续统筹多个工蜂
- 按轮次查看消息、态势与产物
- 从旧轮次继续并生成新分支

和普通蜂群页相比，编排页更强调"持续推进"，而不是一次性协作。

详见 [编排功能](/docs/zh-CN/surfaces/orchestration/)。

## 文件

文件页展示当前智能体可使用的工作目录。用户可以：

- 浏览工作目录的目录结构
- 上传、下载、删除、重命名文件
- 预览文本、图片、PDF 等格式
- 把需要智能体处理的资料放入工作目录，并在聊天中引用文件名或路径

## 智能体

- 查看用户的所有智能体
- 配置模型、工具、提示词
- 添加专属记忆
- 每个智能体可以有多个线程

## 工具与技能

- 查看可用工具列表
- 配置技能（能力包）
- 添加知识库，让智能体参考用户的专属资料

## 定时任务

- 创建定时执行的任务
- 查看执行历史
- 管理、暂停、删除任务
- 手动触发一次执行

## 我的概况与设置

### 我的概况

- 头像、用户名、等级
- 经验进度条
- 使用统计（会话数、工具调用数、Token 消耗）
- 额度账户余额和趋势

### 账户管理

- 修改用户名、邮箱、密码
- 查看所属单位

### 系统设置

- 界面语言切换
- 一键重置工作状态（异常恢复）

### 帮助手册

- 内嵌文档入口，不离开工作台即可查阅

## 状态识别

注意界面上的状态指示：

- 🔄 运行中 = 正在执行
- ⏳ 等待中 = 需要用户输入或审批
- ✅ 已完成 = 可以继续
