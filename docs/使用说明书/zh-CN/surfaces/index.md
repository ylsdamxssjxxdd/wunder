# 界面概览

wunder 的界面分两类：**蜂巢**是所有用户的工作台，**舰桥**是管理员的治理后台。

## 蜂巢：用户工作台

蜂巢是用户日常使用的工作台，覆盖对话、工作目录、智能体设置、工具与设置。默认通过蜂窝（desktop）使用，团队部署舰体后也可以通过浏览器访问网页端：

| 打开方式 | 适合 | 特点 |
|------|------|------|
| **蜂窝** | 个人用户 | 本地安装，可访问本机文件与桌面，开箱即用 |
| **网页端** | 团队成员 | 浏览器访问，多人共用，由舰体统一管理 |

两种方式共用同一套界面与能力。蜂窝在蜂巢基础上额外提供本地文件访问、本地运行时和一键重置。

## 舰桥：治理后台

舰桥面向管理员，负责系统配置、用户管理、渠道监控，与用户的日常使用界面相互独立。

## 蜂巢的左右两栏

蜂窝和网页端都采用左右两栏布局：

```
┌──────────────┬─────────────────────────────┐
│ 左栏         │ 右栏                        │
│ 新任务/搜索   │ 聊天：顶栏 + 时间线 + 输入区  │
│ 工作区线程树  │ 未选中线程时显示欢迎页        │
│ 工作目录      │                             │
│ 设置          │                             │
└──────────────┴─────────────────────────────┘
```

左栏固定 240px，自上而下是：新任务、搜索、工作区与线程树、**工作目录**（文件树 + 工具栏 + 用量条）、底部设置入口。右栏自适应，展示欢迎页或当前线程的聊天页；文件预览、在线编辑等以浮层弹出，不改变两栏结构。

每个用户只有一个智能体实例和一个固定的工作区，所以左栏只有这一条工作区与线程树，没有多智能体的列表、新建或切换入口，也没有更换目录的入口。

## 按角色选择

### 普通用户

主要使用蜂巢：
- 个人用户装[蜂窝](/docs/zh-CN/start/desktop/)
- 团队成员用浏览器访问网页端

### 管理员

主要使用：
- [舰桥](/docs/zh-CN/surfaces/web-admin/)（做治理）
- 蜂巢（做日常工作）

## 常见误区

- **舰桥能聊天？** 不行。舰桥是治理后台，不做日常对话。
- **蜂窝能连接服务器吗？** 当前版本专注本地模式，需要团队协作请用网页端。
- **蜂巢和舰桥共用一套界面？** 不行。职责不同，界面分开。
