# 管理端界面

管理端是**服务端（用户与智能体管理平台）**自带的治理与调试后台。普通用户登录后看不到它，只有管理员能进；日常对话在云端版或桌面版里做。

它跟着服务端一起启动，没有单独的构建步骤，端口和服务端一致（默认 18000）。云端版和它是**两套界面**：云端版面向使用者，管理端面向管理员。

管理端同样遵循极致精简：信息密度服务于定位与决策，能快速解决问题，而不是凸显复杂的元素。

## 顶层导航

管理端共 4 组、19 项。

**系统（4）**

- 内部状态：进程健康、锁与队列、运行时指标
- 系统设置：运行中热更新配置
- 单位管理：组织树，最深 4 级
- 用户管理：账号、配额、在线状态（分云端版 / 桌面版 / 命令行）

**智能体（6）**

- 模型配置：LLM / TTS / 图像 / 视频模型
- 线程管理：跨用户的线程列表、状态、目标态（**只读展示**，没有目标编辑器）
- 预设智能体：智能体模板，可以声明哪些字段允许用户自定义；用户级定时任务和渠道在这里作为模板存在，不是独立导航项
- 形象管理
- 工具管理：把内置工具、MCP、知识库、技能、工具可见范围归在同一组
- 系统提示词：提示词模板

**调试（6）**

- 吞吐量测试：预设输入 1024 到 1 MiB、输出 1024 到 8192，最大并发 1024
- 性能测试：用固定的测试用户和独立数据根，命令超时 5 秒
- 能力评估：跑能力基准并打分
- 多模调试：图像 / 视频 / 转写 / 语音合成直连测试
- 调试面板：线程列表 + 线程详情；**右侧的日志区现在是线程轨迹视图**，旧的日志输出只作为兜底保留
- LSP：语言服务

**文档（2）**

- 使用说明书：站内嵌整个说明书
- 接口：API 文档入口

吞吐量测试与性能测试是管理端的运维面板；面向渲染的线程压测属于用户面，三端的入口默认都是 1000×1000。

## 未实现的管理面板

- **用户级定时任务面板**：没有独立入口，定时只在「预设智能体」里作为模板存在
- **用户级渠道管理**：同上，渠道只在预设模板里
- **长期记忆面板**：没有实现
- **互通治理面板**：互通的舰队 / 通道 / 命令 / 审计 / 策略治理目前只有后端接口，没有界面；说「管理端能管互通」是不对的
- **目标（goal）编辑**：线程管理只读展示，没有目标编辑器；目标入口在用户端——云端版的时间线、桌面版的输入区、命令行的 `/goal` 命令

状态里出现互通、记忆条目但对应面板为空，属于残留的死条目，面板从未落地。

## 操作约束

- 关键动作都有明确的状态、错误反馈和确认边界；前端的确认不能替代后端的权限校验
- 表格、日志和监控面板都做了分页 / 筛选 / 限量，不会一次性铺出大量数据
- 界面密集、适合扫读

## 访问与鉴权

- 地址：`http://<host>:18000/`（默认端口，可在配置里改）
- 鉴权：管理员用 API Key 或登录凭证进入；单位负责人只能管理本单位的单位和用户账号
- 首次登录后请立即修改默认密码
