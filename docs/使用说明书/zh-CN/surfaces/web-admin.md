# 舰桥界面

舰桥是**舰体（用户与智能体管理平台）**自带的治理与调试后台。普通用户登录后看不到它，只有管理员能进。

它跟着舰体一起启动，没有单独的构建步骤，端口和舰体一致（默认 18000）。蜂巢和它是**两套界面**：蜂巢面向使用者，舰桥面向管理员。

## 顶层导航

舰桥共 4 组、19 项。

**系统（4）**

- 内部状态：进程健康、锁与队列、运行时指标
- 系统设置：运行中热更新配置
- 单位管理：组织树，最深 4 级
- 用户管理：账号、配额、在线状态（分蜂巢 / 蜂窝 / 舵机）

**智能体（6）**

- 模型配置：LLM / TTS / 图像 / 视频模型
- 线程管理：跨用户的线程列表、状态、目标态（**只读展示**，没有目标编辑器）
- 预设智能体：智能体模板，可以声明哪些字段允许用户自定义；用户级定时任务和渠道在这里作为模板存在，不是独立导航项
- 形象管理
- 工具管理：把内置工具、MCP、知识库、技能、工具可见范围归在同一组
- 系统提示词：提示词模板

**调试（6）**

- 吞吐量测试：预设输入 1024 到 1 MiB、输出 1024 到 8192，最大并发 1024
- 性能测试：用固定的测试用户和独立数据根，命令超时 5 秒
- 能力评估：跑能力基准并打分
- 多模调试：图像 / 视频 / 转写 / 语音合成直连测试
- 调试面板：线程列表 + 线程详情；**右侧的日志区现在是线程轨迹视图**
- LSP：语言服务

**文档（2）**

- 使用说明书：站内嵌整个说明书
- 接口：API 文档入口

## 舰桥没有的东西

- **用户级定时任务面板**：没有独立入口，定时只在「预设智能体」里作为模板存在
- **用户级渠道管理**：同上，渠道只在预设模板里
- **长期记忆面板**：没有实现
- **互通治理面板**：互通的舰队 / 通道 / 命令 / 审计 / 策略治理目前只有后端接口，没有界面；说「舰桥能管互通」是不对的
- **目标（goal）编辑**：线程管理只读展示，没有目标编辑器；目标入口在用户端——蜂巢的时间线、蜂窝的输入区、舵机的 `/goal` 命令

## 使用注意

舰桥的操作默认是**高风险**的：

- 关键动作都有明确的状态、错误反馈和确认边界；前端的确认不能替代后端的权限校验
- 表格、日志和监控面板都做了分页 / 筛选 / 限量，不会一次性铺出大量数据
- 界面密集、适合扫读

## 访问方式

- 地址：`http://<host>:18000/`（默认端口，可在配置里改）
- 鉴权：管理员用 API Key 或登录凭证进入；单位负责人只能管理本单位的单位和用户账号
- 首次登录后请立即修改默认密码

## 常见问题

**舰桥不做聊天**：它是治理与调试后台，日常对话去蜂巢或蜂窝。

**舰桥与蜂巢是两套界面**：蜂巢是用户面，舰桥是管理员面，两套界面分开。

**状态里有互通、记忆条目但面板为空的原因**：这些是残留的死条目，面板从未落地；互通治理目前只有后端接口。

**日志区已改为线程轨迹视图**：调试面板右侧原来的日志区，现在重构为线程轨迹视图，旧的日志输出只作为兜底保留。

**吞吐量测试、性能测试与线程压测的区别**：吞吐量测试和性能测试是舰桥的运维面板；面向渲染的线程压测属于用户面，三端的入口默认都是 1000×1000。
