# 蜂窝界面

蜂窝（desktop）是本地 AI 工作台，也是个人用户的默认入口：数据留在本机，智能体可以直接读写本地文件。

## 蜂窝特点

### 本地优先

- 数据留在本机，不经手服务器
- 无需部署服务端，装好即用

### 本机文件访问

可以直接访问本机文件系统（在安全边界内），比纯蜂巢更灵活。

### 自带运行时

安装包自带 Python 运行时，省去手动安装和配置。

### 一键重置

异常时可以一键重置工作状态，快速恢复。

## 界面结构

蜂窝复用蜂巢的左右两栏布局，额外提供蜂窝特有的本地能力：

- **左栏**（固定 240px）：新任务、搜索、工作区与线程树、工作目录（文件树 + 工具栏 + 用量条）、底部设置（含蜂窝运行时设置与一键重置）
- **右栏**：欢迎页或聊天页

蜂窝和蜂巢都是「一个用户一个智能体实例 + 一个工作目录」，左栏只有这一条工作区与线程树，没有多智能体的列表、新建或切换入口，也没有更换目录的入口。

## 蜂窝特有功能

### 蜂窝运行时设置

配置本地运行环境：Python 路径、本地工作目录、本地工具配置。

### 一键重置工作状态

**什么时候用**：
- 会话卡在运行中
- 子智能体运行状态不一致
- 界面状态和实际不符

**重置后会**：
- 停止所有运行中的会话
- 清空排队任务
- 重建干净的线程

**保留的内容**：
- 技能、知识库等长期资产
- 用户配置
- 工作区文件
- 会话历史记录

所以重置是「清理工作状态」，不是「恢复出厂设置」。

### 本地文件能力

蜂窝可以让智能体：
- 读取本机文件
- 写入本机文件
- 执行本地命令

这是比蜂巢更强的能力，但受安全边界限制。

## 适用场景

**适合**：
- 个人日常使用
- 需要处理本机文件
- 不想依赖服务器
- 注重隐私和数据本地化

**如果需要**：
- 多用户协作
- 管理员后台
- 组织级部署

请用浏览器访问蜂巢（web，随舰体提供）。

## 常见问题

### 数据在哪里？

- 工作区：本地工作目录
- 会话历史：本地 SQLite 数据库
- 配置：本地配置文件

### 本地模式能联网吗？

可以。本地模式只是数据存本地，不影响联网访问 AI 模型或网页。

### 能迁移到其他电脑吗？

可以。复制工作目录和数据库文件，在新电脑上配置路径即可。
