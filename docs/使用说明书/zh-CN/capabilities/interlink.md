# 三端互通

蛹首先是可离线使用的本地 AI 工作台。登录舰体后，可以在不开放本机端口的情况下访问云端智能体和线程；如用户明确开启本地共享，蜂巢可经舰体中继查看并操作该设备授权范围内的工作区与线程。舵机提供同一能力的手工、脚本化入口。

## 登录与共享

首次在蛹或舵机登录云端后，只获得独立的设备会话；不会自动向蜂巢开放本地文件或线程。用户可在账户设置中选择关闭、摘要共享或完整共享，舰桥还可继续收紧设备能力。

“登录有效”“隧道在线”和“本次操作已获授权”是不同状态：登录用于访问云端；隧道在线才可操作本地设备；写入和执行是否可用还取决于设备能力、策略和审批。

## 前提

1. 蛹或舵机已登录舰体。
2. 需要访问本地设备时，该设备已在线并由用户启用共享。
3. 舰体是账号、设备、额度与策略的唯一权威。

## 能力

| 编号 | 能力 | 说明 |
|------|------|------|
| R1 | 设备状态 | 舰体区分登录会话、隧道连接和可用能力，并显示 `online` / `away` / `busy` / `reconnecting` / `offline` |
| R2 | 工作区互见 | 本地工作区以**影子投影**出现在蜂巢，投影的是元数据摘要（线程目录、目录树摘要、定时任务、用量）；**文件内容不镜像**，按用户操作经互通隧道按需拉取 |
| R3 | 云端控制本地 | 蜂巢可对在线本地节点发起分级操作（查询 / 会话控制 / 工作区写 / 工具执行），敏感操作经本地**人在回路审批**，全程审计 |
| R4 | 本地控制云端 | 蛹/舵机把云端当作对称节点——浏览云端工作区、向云端线程发消息、读取线程事件流；舵机提供脚本化命令组 |

统一状态模型：

| 状态 | 语义 |
|------|------|
| `online` | 在线且空闲 |
| `busy` | 在线且执行中 |
| `away` | 在线但闲置 |
| `reconnecting` | 断线恢复中 |
| `offline` | 离线 |

## 入口

### 蛹

| 入口 | 说明 |
|------|------|
| 账户设置 | 登录状态、是否允许本地共享及共享级别 |
| 云端智能体与线程 | 智能体、最近线程、发送、停止、工具审批、实时状态、历史页和完整原文复制 |
| 本地审批 | 处理蜂巢向本机发出的受控操作 |

### 蜂巢（web）

| 入口 | 说明 |
|------|------|
| 侧栏 | 本地工作区与云端工作区同级展示：默认目录显示为“设备名-本地工作区”，具名目录显示为“设备名-工作区名”；选中某项后在其下展开该工作区的本地线程 |
| 「云端/设备」下拉切换器 | 已移除 |

### 舵机

| 入口 | 说明 |
|------|------|
| `cloud` 子命令组 | `devices` / `ws` / `threads` / `thread` / `send` / `watch` / `audit` / `approve` |
| `cloud status` | 整合四段：互通隧道、待决审批、其他设备、云端工作区用量 |
| `cloud watch` | 帧型为 `snapshot` / `delta` / `command` / `error` / `close` |

## 安全边界

| 边界 | 含义 |
|------|------|
| 零公网入口 | 反向隧道：本地只出站长连接，不开监听端口，控制流复用已建链路下发 |
| 最小能力 | 每类远程操作是声明式能力，默认只开只读 |
| 显式授权 | 写与执行类必须本地用户授权，管理员可在舰桥再收敛 |
| 逐级审批 | L0–L3 风险分层，见下表 |
| 完整审计 | 每次远程操作成链可查 |
| 一键关停 | kill switch 由用户掌握 |

风险分层：

| 级别 | 覆盖的操作 | 审批 |
|------|------|------|
| L0 只读 | `node.summary` / `shadow.refresh` / `workspace.list\|search\|stat\|read` / `threads.list\|get` | 免审批 |
| L0+ | `workspace.read:binary` | 免审批 + 审计 |
| L1 会话 | `thread.create` / `thread.message` / `thread.cancel` / `thread.answer` | 操作本地设备默认需本地审批；操作自己的云端线程由账号鉴权 |
| L2 工作区写 | `workspace.write\|mkdir\|move\|copy\|delete` | 强制审批，不可降 |
| L3 执行 | `tool.exec`（白名单命令） / `agent.spawn` | 强制审批 + 管理员默认禁用，可开 |

- **L3 默认关闭**：`tool.exec` / `agent.spawn` 默认不在设备能力集；审批永不记忆；执行结果只回摘要。
- **L2 写先备份**：写操作先备份到 `工作区/.interlink_backup/<command_id>/`（保留最近 50 代），结果给出前后 SHA256。

## 约束

### 断线与恢复

蛹断线后会按退避策略重新连接。舰体进程持续运行时，尚未发送的有界队列会在设备重连后继续送达；已经发送、正在执行或等待设备审批的命令在旧连接结束时明确失败，避免重复操作。

舰体重启后，遗留命令会分批结算为 `SERVER_RESTARTED`，不会继续显示为等待执行。命令正文不持久化，系统不会从摘要重建参数或自动重做写入。查询可重新发起；写操作应先核对实际结果，再重新发起并按原规则审批。重连后的远程线程视图重新获取快照。

### 边界

- 本地与云端线程不合并。互通是远程操作，不是数据同步。
- 不做工作区文件全量镜像与双向同步，只有元数据投影 + 按需拉取。
- 不做图形化远控，控制粒度止于引擎与文件 API。
- 不做 NAT 穿透打洞，所有流量经舰体中继。
- 蛹与舵机之间不直接互通，本地互访一律经舰体中转。

远程文件读取以 256 KiB 内联结果为界，较大文件通过有界分片传输；云端直执行没有设备数据通道，超过该大小的读写需要拆分。蜂巢不提供二进制上传、归档和批量文件操作。
