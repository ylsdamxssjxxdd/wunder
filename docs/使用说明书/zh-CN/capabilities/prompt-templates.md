# 提示词与个性化

提示词模板决定智能体的角色定位与回答风格。内置模板包有 `default-zh` 与 `default-en` 两套，也可以在界面里自建模板包。

## 提示词模板

一套模板规定四件事：

- 角色定位
- 思考和回答问题的方式
- 工作原则与限制
- 工具和技能的使用方式

换一套模板，智能体的风格和能力侧重随之改变。

## 内置模板包

| 模板包 | 语言 | 适用场景 |
| --- | --- | --- |
| `default-zh` | 用中文思考和回答 | 中文对话场景，默认中文助手风格 |
| `default-en` | 用英文思考和回答 | 英文对话场景，默认英文助手风格 |

按用户主要使用的语言选择对应的模板包。模板只设定默认倾向：即使模板包是 `default-zh`，在对话里明确要求用英文回答，智能体也会遵从。

## 模板包的组成

每个模板包由多个分段拼成：

| 分段 | 作用 |
| --- | --- |
| 角色 | 定义智能体是谁、扮演什么角色 |
| 工程原则 | 定义工作方式和思考方法 |
| 工具协议 | 定义如何使用工具 |
| 技能协议 | 定义如何调用技能 |
| 记忆 | 定义如何使用长期记忆 |
| 附加说明 | 其他补充指令 |

## 切换模板包

### 切换步骤

1. 进入左栏底部「设置」→「智能体」
2. 找到「提示词模板」选项
3. 选择模板包
4. 保存设置

### 生效规则

- **新对话**：切换后创建的新对话使用新模板
- **已有对话**：保持创建时的模板，不变

每个对话在创建时确定提示词并冻结，避免中途改变导致行为前后不一致。已有对话的提示词无法直接修改：新建对话使用新模板，或把原对话的内容复制到新对话继续。

## 创建自定义模板

### 创建步骤

1. 在模板设置页面点「新建模板包」
2. 选一个基础模板复制，从内置模板起步
3. 编辑各个分段的内容
4. 保存后即可使用

### 各分段的写法

- **角色**：写明定位，如「编程助手」「数据分析专家」
- **工程原则**：设定回答风格，简洁或详细、正式或轻松
- **工具协议**：一般不用改
- **附加说明**：放自己的特殊要求

### 编程助手模板示例

角色分段可以这样写：

```
用户是一位专业的编程助手，擅长多种编程语言和软件工程实践。
用户的回答要：
- 代码示例清晰完整
- 解释简洁易懂
- 遵循最佳实践
- 注意安全性
```

## 模板生效的层级

最终提示词由多层组合：

1. **系统模板**：管理员设置的全局基础模板
2. **用户模板**：用户个人选择的模板包
3. **智能体设置**：特定智能体的额外配置

上层覆盖下层，缺失的部分回退到下层。每个智能体独立设置模板。

## 编写要点

- 内置模板可作为起点，之后按需自定义
- 不同场景各建一套模板包
- 关键要求写明确，避免冗余；模板不是越长越好，太长或自相矛盾反而影响效果
- 别把互相矛盾的要求写在一起
- 定期回顾，删掉不再需要的条目
