# 提示词与个性化

提示词模板决定智能体的角色定位和回答风格。可以使用内置模板，也可以自建模板包。

## 提示词模板

提示词模板规定：

- 角色定位
- 怎么思考和回答问题
- 有哪些工作原则和限制
- 怎么使用工具和技能

换一套模板，智能体的风格和能力侧重就会变。

## 内置模板包

wunder 提供两套内置模板包。

### 中文模板包（default-zh）

- 用中文思考和回答
- 适合中文对话场景
- 默认中文助手风格

### 英文模板包（default-en）

- 用英文思考和回答
- 适合英文对话场景
- 默认英文助手风格

按用户主要使用的语言选对应的模板包。

## 模板包的组成

每个模板包由多个分段拼成：

| 分段 | 作用 |
|------|------|
| 角色 | 定义智能体是谁、扮演什么角色 |
| 工程原则 | 定义工作方式和思考方法 |
| 工具协议 | 定义如何使用工具 |
| 技能协议 | 定义如何调用技能 |
| 记忆 | 定义如何使用长期记忆 |
| 附加说明 | 其他补充指令 |

## 切换模板包

### 在界面中切换

1. 进入左栏底部「设置」→「智能体」
2. 找到「提示词模板」选项
3. 选择想要的模板包
4. 保存设置

### 生效规则

- **新对话**：切换后创建的新对话使用新模板
- **已有对话**：不改变，保持创建时的模板

## 创建自定义模板

想进一步定制风格，可以自己建模板包。

### 创建方法

1. 在模板设置页面点「新建模板包」
2. 选一个基础模板复制（建议从内置模板起步）
3. 编辑各个分段的内容
4. 保存后即可使用

### 编辑建议

- **角色分段**：写明定位（如“编程助手”“数据分析专家”）
- **工程原则**：设定回答风格（简洁/详细、正式/轻松）
- **工具协议**：一般不用改
- **附加说明**：放自己的特殊要求

### 示例：编程助手模板

角色分段可以这样写：

```
用户是一位专业的编程助手，擅长多种编程语言和软件工程实践。
用户的回答要：
- 代码示例清晰完整
- 解释简洁易懂
- 遵循最佳实践
- 注意安全性
```

## 模板生效的层级

智能体的最终提示词由多层组合：

1. **系统模板**：管理员设置的全局基础模板
2. **用户模板**：用户个人选择的模板包
3. **智能体设置**：特定智能体的额外配置

上层覆盖下层，缺失的部分回退到下层。

## 常见问题解答

### 切换模板后旧对话不变的原因

每个对话在创建时就确定了提示词，之后保持冻结，以保证对话一致性，避免中途改变导致行为混乱。

### 修改某个对话提示词的办法

已有对话的提示词没法直接改。可以新建一个对话使用新模板，或者把原对话的内容复制到新对话继续。

### 不同智能体可使用不同模板

可以，每个智能体独立设置模板。

### 模板长度并非越长越好

不一定。模板要明确关键要求、避免冗余和冲突。太长或自相矛盾反而影响效果。

### 中文模板可用英文回答

可以，模板只是默认倾向。在对话里明确要求用英文，智能体就会遵从。

## 模板使用建议

- 内置模板可作为起点，之后按需自定义
- 不同场景可以各建一套模板包
- 关键要求写明确，别写得太长
- 别把互相矛盾的要求写在一起
- 定期回顾，删掉不再需要的条目
