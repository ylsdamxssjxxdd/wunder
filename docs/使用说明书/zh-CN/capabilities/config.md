# 系统设置参考

设置按职责分为六类：

- **基础设置**：服务地址、端口、运行模式
- **安全设置**：访问控制、权限边界
- **存储设置**：数据存储位置和方式
- **工具设置**：可用工具范围
- **模型设置**：AI 模型选择和参数
- **渠道设置**：外部平台接入

新设置立即对新会话生效；已有会话不会自动改变，保持创建时的设置。三层配置自下而上依次是**系统默认配置**（所有未指定值回退到这里）、**用户个人设置**（覆盖系统默认，只影响该用户）、**智能体设置**（最上层，只影响该智能体）。生效顺序为智能体设置 > 用户设置 > 系统默认。

## 基础设置

### 服务地址与端口

本地使用保留默认值；团队部署换成团队可访问的地址。

### 运行模式

两种取值：**蛹本地模式**（所有数据存本地）与**舰体模式**（支持多用户和集中管理）。个人使用选蛹本地模式，需要多用户协作或集中管理时选舰体模式。

### 并发限制

同时活跃会话的数量上限。个人使用默认值足够，团队使用按用户数和硬件资源调整。

## 安全设置

### API 密钥

舰桥和舰体接口的访问凭证。密钥要足够复杂——建议超过 16 位，包含字母、数字、特殊字符；不要使用容易被猜到的密钥；定期更换。

### 访问路径控制

限制智能体能访问的文件路径和执行的命令：

- **允许的路径**：指定智能体可以操作的目录范围
- **禁止的模式**：指定禁止访问的文件类型或路径

不要无限制开放整个文件系统：明确指定允许访问的工作目录，禁止访问敏感系统目录。

### 外部认证密钥

把 wunder 嵌入其他系统、或从其他系统调用 wunder 的能力时，用它验证外部请求。

## 存储设置

### 数据库类型

- **SQLite**：轻量级本地数据库，适合蛹本地模式（默认）
- **PostgreSQL**：专业级数据库，适合舰体多用户模式

### 工作区位置

用户文件和智能体产物的存放位置。舰体模式下要确保工作区目录持久化（使用 NAS 或网络存储）；不要把工作区放在临时目录。

### 向量存储

知识库检索功能使用的存储后端，随主存储后端保存：舰体模式使用 PostgreSQL，蛹本地模式使用 SQLite。需要使用知识库检索能力时配置。

## 工具设置

### 内置工具开关

控制哪些内置工具供智能体使用。敏感环境建议关闭命令执行类工具，按实际需求开放必要的工具。

### 浏览器工具

开启后智能体可以浏览网页、截图。本地使用直接启用；舰体部署可能需要 Docker 容器支持。

### MCP 扩展工具

通过 MCP 协议接入外部工具服务。需要专业数据库操作、特定 API 调用或接入第三方服务时使用。

## 模型设置

### 可用模型列表

智能体可以选择的 AI 模型清单。

- 添加模型时需要填写 API 密钥和接口地址
- 不同模型有不同的计费方式和能力特点
- 建议提供多个选项让用户按需选择

### 上下文限制

对话上下文长度的上限。设置为模型支持的最大值即可，超出时系统会自动压缩历史内容。

## 渠道设置

### 渠道账号绑定

绑定飞书、企业微信等外部平台账号。需要在对应平台创建应用并获取凭证，按渠道类型填写相关配置。

### Webhook 配置

外部平台向 wunder 推送消息的接收地址。设置一个可公开访问的地址，并在外部平台配置 Webhook URL。

## 部署形态

| 项 | 个人本地使用（蛹 desktop） | 团队协作（舰体 server） |
| --- | --- | --- |
| 数据库 | SQLite（默认） | PostgreSQL |
| 工作区 | 本地目录 | 网络存储（持久化） |
| 安全 | 适度限制敏感路径 | 严格配置密钥和路径限制 |
| 工具 | 按需开放 | 按角色分配权限 |
