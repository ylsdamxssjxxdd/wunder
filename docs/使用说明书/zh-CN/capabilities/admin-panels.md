# 舰桥面板指南

舰桥走独立地址访问：浏览器打开舰桥 URL，用管理员账户登录后即可使用各面板。地址由部署时确定，向系统部署人员索取或查看部署文档。面板按系统、智能体、调试、文档四个分组组织。

舰桥持有系统最高权限：

- 只有授权的管理员才能访问
- 管理员账户密码要足够复杂
- 定期更换管理员密码
- 操作前确认影响范围，避免误操作
- 重要操作做好记录

| 我要... | 去哪个面板 |
|---------|------------|
| 添加用户 | 用户管理 |
| 给用户发放额度 | 用户管理 → 点击用户 → 设置 |
| 查看系统运行状态 | 内部状态 |
| 调整系统配置 | 系统设置 |
| 添加新模型 | 模型配置 |
| 查看活跃会话 | 线程管理 或 内部状态 |
| 处理卡住的线程 | 线程管理 → 取消 |
| 测试系统性能 | 性能测试 或 吞吐量测试 |
| 查看使用方法 | 使用说明书 |

## 系统分组

### 内部状态

查看系统运行状态：

- 活跃会话数
- 系统负载
- 关键组件状态

### 系统设置

全局参数：

- 服务地址和端口
- 安全设置
- 存储设置
- 工具开关

调整一项系统设置：

1. 系统设置 → 找到对应配置项
2. 修改设置值
3. 保存（通常立即生效）
4. 在内部状态确认效果

### 单位管理

管理组织架构：

- 创建和管理单位
- 单位层级关系
- 单位成员管理

### 用户管理

管理用户账户：

- 用户列表查看
- 创建新用户
- 编辑用户信息
- 额度账户管理（发放、扣除、设置余额）

用户设置里的额度操作：

- **直接设置余额**：覆盖当前余额，适合修正账面值
- **发放额度**：增加余额，记录累计获得
- **扣除额度**：减少余额，记录累计消耗
- 管理员账户不受额度余额限制

用户列表里的在线状态按客户端拆分展示：蜂巢在线（网页端）、蛹在线（桌面端）、舵机在线（命令行）。

新用户加入：

1. 用户管理 → 创建用户
2. 设置用户名、密码、所属单位
3. 根据需要发放额度
4. 用户即可登录使用

- 查看与批量调整绑定用户（绑定 / 换绑 / 解绑），解绑必须指定新预设
- 同步到绑定用户实例（同步未自定义项 / 强制覆盖，支持 dry-run 预览影响用户数）

## 调试分组

### 吞吐量测试

测试参数：选模型、并发列表、输入长度和输出长度。每次按列表顺序测试一个并发档，并同时发起指定数量的请求。默认并发列表为 `1,2,4,8`，输入为 `8.2k` Token，输出为 `128` Token；输入和输出保留常用档位，也可直接输入范围内的整数。

读数：页面中 Token 数量从 1,000 起显示为 `k`，从 100,000 起显示为 `m`；历史快照显示 API 实测输入用量；右侧显示聚合后的实际输入输出、首字延迟、生成速度和总耗时；历史曲线以并发数为横轴展示整体与单请求速度。

- 支持的推理引擎会接收定长输出参数，其他接口可能提前结束；实际用量和结束原因会在详情中保留。
- 测试不创建会话或线程日志，仅保存最近 50 次性能摘要。
- 详情和曲线区分整体预填充/生成速度、单预填充速度和单生成速度；速度从 1,000 起使用 `k tok/s`，从 100,000 起使用 `m tok/s`。
- 勾选历史记录即可按并发数比较性能曲线：纵轴以并发 1 为 0% 基线展示相对变化，悬停可查看实测速度，也可复用配置或导出所选数据。

虚拟模型在模型配置里可选快 / 中 / 慢，默认快：预填充 2000 / 500 / 100 Token/s，思考与生成 200 / 50 / 10 Token/s。随机模拟回复与吞吐模拟都会先思考再生成内容，回放日志在配置的能力与预算内使用原有思考内容。吞吐测试的思考量默认占输出总数 1/4，可通过思考开关与预算调整；模拟记录按速度单独标记和分组。

### 模拟模型能力

模型配置选择虚拟模型后，可设置最大上下文、最大输出、视觉、听觉、思考和工具能力。上下文与输出留空时分别为 128k / 4k；输入（包括工具定义）加输出预算超过窗口，会报告上下文超限。关闭视觉或听觉后，相应媒体请求报错。图片、音频可分别设置每项 token 数，仅模拟用量和耗时，不识别内容。

回放时使用“工具调用方式”：`function_call` 走原生工具通道，`tool_call` 走文本协议，`freeform_call` 根据 API 模式使用原生或文本回退。工具名称与参数直接来自日志，无需手填；工具执行仍遵守权限和审批，结果返回后继续回放下一模型轮次。日志耗尽会报错，不重复执行旧调用。合成回复不主动调用工具。输出过长会标记长度终止，不完整的工具参数不会执行；思考能力和预算也作用于吞吐测试。

### 随机模拟的轮次约定

没有可用回放日志时，随机模拟按本回合人类输入里的约定展开，各形态（蛹、蜂巢、舵机）一致：

- 轮次数：输入里第一个数字决定本次模型轮次数，可带 `s` / `轮` / `次` 后缀（`12`、`12轮`、`1s` 都算 12 或 1）。上限 2000，小于 1 按 1 计。数字只取本回合的人类输入，不取历史，也不会因为上下文压缩改写历史而改变。
- 派生子智能体：输入含 `subagent`、简拼 `s` / `sub`、`子智能体` / `子代理`，或数字后直接带 `s`（`1s`），首个模型轮次必定发出一次真实的子智能体派生调用（`spawn` 或 `batch_spawn`）。此时计划至少两轮：一轮派生、一轮收尾，因此 `1s` 也会先派出子智能体再回答。
- 中间轮次从本次请求提供的工具里挑选只读类工具发出无害调用，最后一个轮次输出总结。计划由（会话、用户轮次）确定性推导，取消后恢复一致。
