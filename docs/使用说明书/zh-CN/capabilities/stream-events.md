# 会话状态说明

对话过程中，界面会显示思考中、正在调用工具、压缩上下文、出错重试等状态。

## 状态概览

一个对话从开始到结束经历的状态：

```
等待 → 思考/执行 → 完成
          ↓
       需要审批 → 等待用户的决定 → 继续
          ↓
       出错/取消 → 结束
```

## 基本状态

| 状态 | 含义 | 出现时机 | 处理 |
| --- | --- | --- | --- |
| 等待中 | 请求已提交，正在排队等待处理 | 系统繁忙；多个请求同时进行 | 等待 |
| 正在思考 | 智能体正在分析请求，准备回答或执行操作 | 模型理解问题与生成方案期间 | 等待，不要重复发送同一条消息 |
| 正在执行工具 | 智能体正在用工具完成任务：读取文件、搜索网页、执行代码等 | 复杂任务需要多个工具配合 | 在进度区域查看执行进度 |
| 已完成 | 智能体完成请求并给出最终回答 | 请求处理结束 | 继续提问、查看生成的内容或文件、开始新任务 |

执行工具期间界面会出现「正在读取文件…」「正在搜索…」「正在执行…」这类提示。

## 审批状态

| 状态 | 含义 | 处理 |
| --- | --- | --- |
| 需要审批 | 智能体要执行需要确认的操作：修改重要文件、执行敏感命令；或已配置审批模式 | 界面给出审批请求与具体操作说明，点「批准」继续，点「拒绝」阻止 |
| 审批已处理 | 已对审批请求做出决定 | 批准后智能体继续执行该操作；拒绝后放弃该操作，可能另想办法 |

进入审批是因为该操作可能有风险或影响重要文件，属于安全保护机制。想减少审批，与管理员沟通调整审批模式。

## 异常状态

| 状态 | 含义 | 常见原因 | 处理 |
| --- | --- | --- | --- |
| 执行失败 | 执行中遇到问题，没能完成任务 | 文件不存在或无法访问；网络请求失败；工具执行出错；模型服务异常 | 看错误提示确认原因，按提示调整请求（如给出正确的文件路径），重试 |
| 已取消 | 对话被用户或系统主动终止 | 点了「停止」；系统超时自动取消；其他主动终止 | 重新开始对话，或查看取消前的执行记录 |
| 会话卡住 | 长时间停在一个状态，没有进展 | 网络连接中断；后端服务异常；任务处理超时 | 先等几分钟；确认卡住后点「停止」；用设置里的「重置工作状态」清理异常状态；仍不恢复则联系管理员 |

## 连接状态

| 状态 | 含义 | 症状与处理 |
| --- | --- | --- |
| 已连接 | 与后端服务的网络连接正常 | — |
| 连接断开 | 与后端服务的网络连接中断 | 无法发送新消息、状态显示异常、提示「连接已断开」；检查网络，刷新页面或重启应用，等待自动重连 |

## 状态指示器位置

| 位置 | 显示内容 |
| --- | --- |
| 对话框上方 | 当前会话的整体状态 |
| 消息气泡旁 | 该消息的处理状态 |
| 进度区域 | 工具执行的详细进度 |
| 对话下方或右侧 | 执行轨迹与工具调用记录：调用了哪些工具、读了哪些文件、执行了什么操作 |

## 排查

**响应变慢**：任务复杂需要多步执行、模型服务响应延迟、系统负载较高都会拉长响应时间。等待即可，不要重复发送同一条消息。

**状态显示异常**：先等待看是否自动恢复；未恢复用「重置工作状态」；再不行刷新页面或重启应用。仍未解决按[故障排查](/docs/zh-CN/help/troubleshooting/)处理。
