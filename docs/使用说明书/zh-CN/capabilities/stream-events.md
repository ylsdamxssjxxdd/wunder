# 会话状态说明

对话过程中，界面会显示思考中、正在调用工具、压缩上下文、出错重试等状态。

## 状态概览

一个对话从开始到结束，通常会经历这些状态：

```
等待 → 思考/执行 → 完成
          ↓
       需要审批 → 等待用户的决定 → 继续
          ↓
       出错/取消 → 结束
```

## 基本状态

### 等待中

**含义**：请求已提交，正在排队等待处理。

**什么时候出现**：
- 系统繁忙时
- 有多个请求同时进行时

**怎么办**：等待。

### 正在思考

**含义**：智能体正在分析你的请求，准备回答或执行操作。

模型理解问题和生成方案需要时间。等待期间不要重复发送同一条消息。

### 正在执行工具

**含义**：智能体正在用工具完成任务（读取文件、搜索网页、执行代码等）。

**可能看到的提示**：
- "正在读取文件..."
- "正在搜索..."
- "正在执行..."

复杂任务往往要多个工具配合，界面上能看到执行进度。

### 已完成

**含义**：智能体完成了请求，给出了最终回答。

- 继续提问
- 查看生成的内容或文件
- 开始新的任务

## 审批状态

### 需要审批

**含义**：智能体想执行一个需要你确认的操作（比如修改重要文件、执行有风险的命令）。

**什么时候出现**：
- 智能体想修改重要文件
- 智能体想执行敏感命令
- 配置了审批模式时

**你会看到**：
- 一个审批请求弹窗或提示
- 智能体想执行的具体操作说明

**怎么办**：
- 仔细看操作说明
- 决定批不批
- 点"批准"继续，或点"拒绝"阻止

### 审批已处理

**含义**：你已经对审批请求做出了决定。

**两种结果**：
- **批准了**：智能体继续执行该操作
- **拒绝了**：智能体放弃该操作，可能另想办法

## 异常状态

### 执行失败

**含义**：智能体执行中遇到问题，没能完成任务。

**可能的原因**：
- 文件不存在或无法访问
- 网络请求失败
- 工具执行出错
- AI 模型服务异常

**怎么办**：
- 看错误提示了解原因
- 按提示调整请求（比如给出正确的文件路径）
- 重试

### 已取消

**含义**：对话被用户或系统主动终止。

**什么时候出现**：
- 点了"停止"按钮
- 系统超时自动取消
- 其他主动终止

取消后可以重新开始对话，或查看取消前的执行记录。

### 会话卡住

**症状**：长时间停在一个状态，没有进展。

**可能的原因**：
- 网络连接中断
- 后端服务异常
- 任务处理超时

**怎么办**：
1. 先等几分钟（有时只是处理时间长）
2. 确实卡住了，点"停止"
3. 用"重置工作状态"功能清理异常状态（在设置里）
4. 还不行就联系管理员，或看故障排查指南

## 连接状态

### 已连接

**含义**：与后端服务的网络连接正常。

### 连接断开

**含义**：与后端服务的网络连接中断。

**症状**：
- 无法发送新消息
- 状态显示异常
- 提示"连接已断开"

**怎么办**：
- 检查网络
- 刷新页面或重启应用
- 等待自动重连

## 状态指示器位置

聊天界面上，这些位置会显示状态：

- **对话框上方**：当前会话的整体状态
- **消息气泡旁**：该消息的处理状态
- **进度区域**：工具执行的详细进度

## 常见问题解答

### 响应变慢的原因

可能原因：
- 任务复杂，需要多步骤执行
- AI 模型服务响应延迟
- 系统负载较高

建议：等待，不要重复发送。

### 智能体等待审批的原因

因为该操作可能有风险或影响重要文件。这是安全保护机制，确保敏感操作经过确认。想减少审批，可以和管理员沟通调整审批模式。

### 状态显示异常的处理

1. 先等待，看是否自动恢复
2. 用"重置工作状态"功能
3. 刷新页面或重启应用
4. 查看故障排查指南

### 查看智能体近期操作的方法

对话界面下方或右侧通常有执行轨迹或工具调用记录，能看到智能体调用了哪些工具、读了哪些文件、执行了什么操作。
