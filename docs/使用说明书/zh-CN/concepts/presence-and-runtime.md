# 运行时与在线状态

一条对话不只是聊天记录，还带着**运行时状态**，表示这条会话当前在做什么。

## 两层状态

**一是会话此刻在做什么**：

| 状态 | 含义 |
| --- | --- |
| 正在执行 | 正在跑 |
| 等待审批 | 停在某个需要你点头的动作上 |
| 等待用户输入 | 智能体在等你补充信息 |
| 正在中断 | 正在被打断 |
| 空闲 | 没事做，等你的下一条消息 |
| 未加载 | 还没被加载进内存 |

**二是给界面直接用的汇总快照**：是否正在持续输出、是否在等待、是否已加载、是否活跃、是否已经有终态。

## 界面上体现在哪

- **会话列表**：状态徽标直接来自运行时状态——绿点=活跃会话，旋转图标=正在执行，等待图标=等待审批或输入。
- **会话详情**：状态指示器显示当前在哪个阶段、能不能发新消息、有没有待处理的审批。

## 卡住时怎么判断

运行时状态是排障的起点：

| 想知道 | 看什么 |
| --- | --- |
| 是否还在执行 | 是否正在持续输出 |
| 是否在等待 | 是否处于等待态 |
| 是否已结束 | 是否已有终态 |
| 还能不能继续观察 | 是否已加载、是否活跃 |

别只看一个笼统的"运行中 / 没运行"：它区分不出"在持续输出"和"在等审批"，也区分不出会话有没有加载、有没有终态。要看完整的这组快照字段。

## 状态不一致时

界面显示和实际对不上时：

1. 等几秒，看是否自动恢复。
2. 刷新页面或重启应用。
3. 用"重置工作状态"。

## 容易搞错的地方

- 等待审批是**暂停**，不是结束——它仍在会话生命周期内。
- 状态不只详情页要看，列表、事件页也要显示。
- 事件流负责时间线，运行时快照负责"此刻"，两者不是同一层。
