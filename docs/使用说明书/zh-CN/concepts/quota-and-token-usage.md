# 额度与 Token 用量

额度用于限制模型请求次数。普通用户每天统一获得 **1000 额度**，与单位、等级无关。未用完可累计；当天首次使用或调整账户时入账一次，不补发未使用日期。

每次实际请求模型扣 **1 额度**，包括工具循环中的下一次模型调用、压缩摘要和失败重试。流式分片、单独执行工具及历史回放不扣额度。发出的请求即使失败也消耗额度；不足时不会发送新模型请求。管理员和未注册的虚拟用户沿用免额度限制。

## 查看和调整

用户侧“我的概况”显示当前额度和每日发放。管理员在“用户管理 → 设置”中可直接设置额度余额，或发放 / 扣除额度。直接设置的数值是当天发放结转后的最终余额；发放增加累计获得，扣除计入累计使用，余额不足会拒绝操作。

| 字段 | 含义 |
| --- | --- |
| `quota_balance` | 当前可用额度 |
| `quota_granted_total` | 累计发放 |
| `quota_used_total` | 累计使用及管理员扣除 |
| `daily_quota_grant` | 每日发放额度 |
| `last_quota_grant_date` | 最近发放日期 |

多个线程共享同一个用户额度账户，并发请求不能透支。用户等级继续积累经验，但不再奖励额度。首次升级时旧 Token 余额账户初始化为 1000 额度，不按历史 Token 数换算；之后重启不重置余额。

## Token 统计

Token 用量继续用于观察模型输入、输出、思考以及上下文大小，**不参与额度扣减**。短请求和长请求均扣 1 额度。

- `context_occupancy_tokens`：最近一次实际观测的上下文占用。
- `request_consumed_tokens` / `round_usage.total_tokens`：一次用户请求内的累计模型 Token 消耗。
- `token_usage` / `model_usage`：模型用量事件。
- `quota_usage`：额度账户快照事件。
