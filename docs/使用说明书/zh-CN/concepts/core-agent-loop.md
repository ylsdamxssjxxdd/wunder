# 智能体循环

循环解决一件事：**用户只说一次目标，中间步骤不需要人指挥**。它不是"一问一答"，而是引擎主循环反复调用模型，每次调用可以带一批工具执行，直到得出可交付的结果或撞到一个明确的刹车。

## 循环长什么样

```
受理用户轮次
  └─ 主循环（模型轮次 = 一次模型调用）
       1. 让位检查 + 轮次上限检查
       2. 必要时压缩上下文
       3. 调模型 → 得到文本或工具调用
       4. 有工具调用：并行/独占执行 → 结果作为观察写回历史
       5. 无工具调用（或命中刹车）→ 落终态，退出
```

**粒度口径**（与[会话与轮次](/docs/zh-CN/concepts/sessions-and-rounds/)一致）：

- 一个模型轮次 = 引擎主循环的一次模型调用（`orchestrator/execute.rs` 里的 `model_round += 1`）。
- 一个模型轮次内**可以有多个工具调用**，工具调用不单独计模型轮次。
- 一个模型轮次恰好对应**一个可见输出项** `{turn_id}:text-{model_round}`；工具批次在时间线里是独立条目，但不是独立模型轮次。

## 刹车与护栏

| 护栏 | 边界 | 触发后的表现 |
| --- | --- | --- |
| 模型轮次上限 | 非管理员默认 1000 | 停止并记 `stop_reason=max_rounds` |
| 单轮工具调用预算 | 10000 次；记忆召回 2000；库查询类 2000（可放大到 10000） | 超出后该类的后续调用被拒 |
| 同指纹失败熔断 | 非重试类 5 次、参数/协议错 2 次、"成功但无进展"4 次 | 停止重复调用，转述失败原因 |
| 上下文超限自愈 | 最多 8 次恢复尝试 | 每次先做修复压缩再重试 |
| 空输出保护 | 一次性重试 1 次（关闭推理强度后重采） | 仍无效则报 `LLM_OUTPUT_LOOP` 并停 |
| 模型/工具超时 | 各默认 120 秒，空闲看门狗 | 超时按失败进入熔断计数 |
| 会话锁 | TTL 120 秒、心跳 5 秒 | 同线程串行，占用方异常退出由 TTL 释放 |
| 活跃会话上限 | 非管理员受 300 约束 | 排队或提示稍后再试 |
| 工具并行度 | ≤ 4，读锁并行、独占工具写锁 | 大批只读调用分批推进 |

审批与风险分层独立于循环：写/执行类调用会挂起等待人工决定，批准结果按工具类别缓存 600 秒，重复同类操作不再追问。

## 终态

每轮循环最终必须落到一个结果，界面状态由此判断：

| 终态 | 含义 | 常见 `stop_reason` |
| --- | --- | --- |
| `completed` | 本轮正常结束，给出可交付回复 | `model_response`、`yield`、`question_panel` |
| `rejected` | 请求未被受理（忙、配额不足、请求非法） | 对应错误码 |
| `cancelled` | 用户主动停止 | `CANCELLED` |
| `failed` | 执行过程出错 | 工具护栏、无进展守卫、模型错误 |

等待人工输入或审批时线程**不是终态**，状态分别为 `waiting_user_input`、`waiting_approval`。

## 线程是执行主体

- 一个智能体可同时拥有多个独立任务线程；调度、锁与实时状态都按线程隔离，不同线程互不阻塞。
- 线程首次确定系统提示词后即**冻结**，长期记忆只在初始化时注入一次，后续轮次不再改写（`orchestrator/prompt.rs`）。这让长任务的行为稳定，也让模型侧的提示词缓存可复用。
- 子智能体是主智能体临时创建的工作单元，运行自己的循环，结果回传父线程；任务结束即回收。协作形态**只有这一种**，蜂群编排已从引擎与调度面移除。

## 实践

**该等的情况**：看到"正在执行工具"或多个工具条目连续出现，说明循环正常推进。重复发同一句话不会加速，只会新增用户轮次排队。

**该介入的情况**：

- 弹出审批 → 决定批准或拒绝，拒绝会落 `rejected`。
- 问询面板提问 → 线程转入等待人工输入。
- 方向不对 → 直接补一条指令，新用户轮次会带上新上下文。
- 长时间无输出且状态仍为 `running` → 用停止（`cancel`）落到 `cancelled`，再重述目标。

**该开新线程的情况**：话题切换、上下文已经很长、或需要一份干净的提示词底座（改了智能体设定或记忆后，只有新线程生效）。

## 常见误解

- **"每调用一次工具就是一轮"** —— 不是。工具批次属于同一个模型轮次。
- **"循环会无限重试"** —— 不会。同指纹失败、无进展成功、超限与空输出都有熔断。
- **"界面不动 = 循环停了"** —— 先看状态：`waiting_approval` / `waiting_user_input` / `queued` 都仍在生命周期内。
- **"流式输出就是循环"** —— 流式只是展示方式；循环的真相在线程台账里，见[流式执行](/docs/zh-CN/concepts/streaming/)。
- **"子智能体共享父线程上下文"** —— 子智能体是独立线程、独立循环，只通过回传与信箱交互。
