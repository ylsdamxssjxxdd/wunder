# 目标

目标挂在会话上之后，智能体按它持续工作，直到完成、受阻或用完轮次预算。

## 驱动工具

| 工具 | 作用 |
| --- | --- |
| `get_goal` | 读出当前目标及其版本号 |
| `create_goal` | 创建目标 |
| `update_goal` | 编辑、暂停、恢复、完成、报告受阻 |

## 相位

四种取值：`active`（活跃）、`paused`（挂起）、`blocked`（受阻）、`complete`（已完成）。

更新走 CAS-on-revision：更新必须带上目标当前的版本号，对不上就被拒绝。已启动轮次只增不减。

## 默认值

| 项 | 值 |
| --- | --- |
| 目标轮上限 | 256 |
| 连续无进展自动受阻 | 3 轮 |

## 入口

| 入口 | 位置 |
| --- | --- |
| 接口 | `/wunder/chat/sessions/{id}/goal` |
| 斜杠命令 | `/goal` |

## 限制

- 目标没有 token 预算，轮次之间也没有冷却。是否停下只看轮次预算、相位与是否 armed。
- armed 状态**不持久**：进程重启或会话 resume 之后，即使相位仍是 `active`，也需要显式 `update_goal action=resume` 重新 arm。目标不动了先查它有没有被 arm。
- 桌面端不开放目标选择，运行时按会话注入。
- 舰桥没有 goal 界面，目标操作在蜂巢、蛹、舵机里做。
