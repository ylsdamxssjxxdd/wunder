# wunder 心舰

<p class="docs-eyebrow">多形态的智能体工作台</p>

给出目标后，智能体自行拆解任务、调用工具并交付结果。

## 形态

四个形态构建在同一套引擎之上：

| 形态 | 定位 | 谁用 |
| --- | --- | --- |
| **蛹** | 本地 AI 工作台，装在自己电脑上 | 个人用户（默认入口） |
| **蜂巢** | 云端 AI 工作台，浏览器里打开 | 部署舰体后的团队成员 |
| **舵机** | 手工本地操作入口，终端里使用 | 命令行用户 / 自动化脚本 |
| **舰体** | 用户与智能体管理平台，多人共用 | 管理员 |

见 [形态矩阵](/docs/zh-CN/start/forms/)。

蛹和舵机不依赖舰体，可单独安装运行。**舰桥**是舰体自带的管理界面，随舰体一起启动，面向管理员。

其余形态按需部署：**舰体（server）**多人共用、权限管理、渠道接入、统一发布，见 [舰体部署](/docs/zh-CN/start/server/)；**蜂巢（web）**随舰体提供，部署后成员用浏览器访问；**舵机（cli）**用于终端与自动化场景，见 [舵机使用](/docs/zh-CN/start/cli/)。

## 默认入口

个人用户的默认入口是蛹：下载安装，打开就是一个本地 AI 工作台。

```text
下载蛹 → 配置模型 → 描述目标 → 拿到结果
```

细节见 [快速开始](/docs/zh-CN/start/quickstart/) 与 [蛹入门](/docs/zh-CN/start/desktop/)。

## 能力范围

- **文件与代码**：读取、编辑、执行命令、重构项目
- **办公自动化**：整理文档、生成报告、处理表格、做会议纪要
- **并行子任务**：需要同时推进多条线时，主智能体会临时派生几个子智能体分头去做，结果回传后汇总
- **定时任务**：定时巡检、周期提醒、跨渠道消息处理
- **连接外部服务**：把常用流程固化成技能
- **设备互通**：本地设备接入云端后，云端可在获得你审批的前提下向本地节点下发命令

## 并发任务与会话队列

- 同一个智能体下可以**同时挂多个独立任务线程**，互不干扰。
- 工作区也可以有多个：本地目录、云端工作区、通过设备互通访问的远程设备工作区，在界面上按名字区分。
- 运行中再发消息不会被打回：**会话队列**默认开启，新的消息进入队列等待，而不是被判「用户忙」。
