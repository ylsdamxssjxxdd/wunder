# wunder 心舰

<p class="docs-eyebrow">会执行任务的 AI 工作台</p>

## 蜂窝：你的 AI 工作台

用户通过**蜂窝（desktop）**使用 wunder。蜂窝是本地桌面应用，覆盖对话、文件、智能体、工具与设置。安装后打开，描述目标，智能体拆解任务、调用工具、交付结果——不需要先部署任何服务。

```text
下载蜂窝 → 配置模型 → 描述目标 → 拿到结果
```

个人用户从 Releases 下载安装即可开始；[快速开始](/docs/zh-CN/start/quickstart/) 4 步跑通第一个任务。

## 能做什么

- **文件与代码**：读取文件、编辑代码、执行命令、重构项目
- **办公自动化**：整理文档、生成报告、处理表格、做会议纪要
- **任务拆分**：需要并行推进时，由智能体临时派生子智能体分头执行，结果回传后汇总
- **持续任务**：定时巡检、周期提醒、跨渠道消息处理
- **系统集成**：连接外部服务，把常用流程固化成技能

## 工作台结构

蜂窝采用左右两栏布局：左栏放新任务、搜索、工作区线程树、工作目录与设置，右栏是聊天。日常对话、文件读写、智能体设置、工具使用都在这里完成。每个用户只有一个智能体实例和一个固定的工作目录。详见 [认识蜂巢](/docs/zh-CN/surfaces/frontend/)。

系统的组织结构自上而下：

![心舰到线程的自上而下结构：心舰、用户、智能体、线程逐层落到具体对话。](/docs/assets/manual/08-hierarchy-structure.svg)

用户发消息 → 智能体在线程里持续执行；需要拆分时由它临时派生子智能体。

## 核心特性

| 特性 | 说明 |
|------|------|
| **本地优先** | 蜂窝本地运行，开箱即用，可操作本地文件与桌面 |
| **单智能体 + 子智能体** | 每个用户只有一个智能体实例；可并行的工作由临时子智能体分担 |
| **丰富的工具生态** | 内置工具 + MCP 外部工具 + 技能包 + 知识库 |
| **长会话** | 上下文压缩与长期记忆，长会话可以一直工作下去 |
| **开放接口** | WebSocket 实时通信、RESTful API、A2A 互操作标准 |

## 需要更多？两个可选形态

蜂窝覆盖绝大多数场景。wunder 还提供两种可选形态，按需取用：

- **舰体（server）**：需要多人共用、统一治理时才部署。多用户、权限管理、渠道接入，成员通过浏览器访问网页端。见[舰体部署](/docs/zh-CN/start/server/)，管理界面见[舰桥](/docs/zh-CN/surfaces/web-admin/)。
- **舵机（cli）**：终端与自动化场景使用，脚本化驱动。见[舵机使用](/docs/zh-CN/start/cli/)。
