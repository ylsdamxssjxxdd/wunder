# wunder 心舰

<p class="docs-eyebrow">多形态的智能体工作台</p>

给出目标后，智能体自行拆解任务、调用工具并交付结果。

## 形态

多个形态构建在同一套引擎之上，其中桌面版、安卓版与命令行是本地形态：

| 形态 | 定位 | 谁用 |
| --- | --- | --- |
| **wunder 桌面版** | 本地 AI 工作台，装在自己电脑上 | 个人用户（默认入口） |
| **wunder 安卓版** | 桌面版的 Android 形态，装在自己手机上 | 手机用户 |
| **wunder 云端版** | 云端 AI 工作台，浏览器里打开 | 部署服务端后的团队成员 |
| **wunder 命令行** | 手工本地操作入口，终端里使用 | 命令行用户 / 自动化脚本 |
| **wunder 服务端** | 用户与智能体管理平台，多人共用 | 管理员 |

见 [形态矩阵](/docs/zh-CN/start/forms/)。

桌面版、安卓版和命令行不依赖服务端，可单独安装运行。**管理端**是服务端自带的管理界面，随服务端一起启动，面向管理员。

其余形态按需部署：**服务端（server）**多人共用、权限管理、渠道接入、统一发布，见 [服务端部署](/docs/zh-CN/start/server/)；**云端版（web）**随服务端提供，部署后成员用浏览器访问；**命令行（cli）**用于终端与自动化场景，见 [命令行使用](/docs/zh-CN/start/cli/)；**安卓版（android）**用于手机与移动场景，安装 APK 即可。

## 默认入口

个人用户的默认入口是桌面版：下载安装，打开就是一个本地 AI 工作台。

```text
下载桌面版 → 配置模型 → 描述目标 → 拿到结果
```

细节见 [快速开始](/docs/zh-CN/start/quickstart/) 与 [桌面版入门](/docs/zh-CN/start/desktop/)。

## 能力范围

- **文件与代码**：读取、编辑、执行命令、重构项目
- **办公自动化**：整理文档、生成报告、处理表格、做会议纪要
- **并行子任务**：需要同时推进多条线时，主智能体会临时派生几个子智能体分头去做，结果回传后汇总
- **定时任务**：定时巡检、周期提醒、跨渠道消息处理
- **连接外部服务**：把常用流程固化成技能
- **设备互通**：本地设备接入云端后，云端可在获得你审批的前提下向本地节点下发命令

## 并发任务与会话队列

- 同一个智能体下可以**同时挂多个独立任务线程**，互不干扰。
- 工作区也可以有多个：本地目录、云端工作区、通过设备互通访问的远程设备工作区，在界面上按名字区分。
- 运行中再发消息不会被打回：**会话队列**默认开启，新的消息进入队列等待，而不是被判「用户忙」。
