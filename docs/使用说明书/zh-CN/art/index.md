# 美术设计稿

这一组图是两套本地形态的界面基线：蛹（桌面端）在前，是主线；舵机（终端端）在后。每张图同时给出尺寸、颜色、状态和规则，代码以图为准；图与代码冲突时，先核对实机再决定改哪边。

- 源文件在 `docs/wunder美术设计稿`，按形态分 `蛹/` 与 `舵机/` 两个子目录；每张都是可单独打开的 SVG，蛹稿的图标已内嵌，单张拷走也能完整显示
- 页面直接展示 SVG，可缩放；蛹稿也可以打开[设计稿索引](/docs/art/)，按缩略图浏览全部十张
- 蛹的帮助手册另外内嵌蛹稿的位图预览，避免在 Slint 里引入 SVG 渲染链；舵机稿面向终端实现，不进蛹内嵌手册

## 维护方式

改完 SVG 后在本仓库根目录运行一次：

```bash
python scripts/sync_art.py
```

它会依次完成三件事：

1. 把蛹稿 SVG 渲染成 1200px PNG，写到 `frontend-slint/assets/help/art`（蛹内嵌用）
2. 用这些 PNG 重建蛹的中英手册 JSON
3. 重建文档站，并把 SVG 复制到 `web/docs/art`（蛹）与 `web/docs/art/servo`（舵机）；复制时自动把应用图标内嵌为 data URI

Web 端重建站点后即生效；蛹需要重新编译桌面程序，预览图是用 `include_bytes!` 编进二进制的。

蛹新增或删除分页时，除了图本身，还要同步三处：`scripts/render_art_previews.py` 的 `SHEETS`、`scripts/build_help_manual.py` 的 `ART_TOPICS`、以及画廊 `docs/wunder美术设计稿/蛹/index.html`；本页的章节也补上，然后再运行同步脚本。不要手改 `frontend-slint/assets/help/art` 里的 PNG。

舵机新增或删除分页时，同步本页章节与 `docs/wunder美术设计稿/舵机/README.md` 的文件表即可，不涉及蛹内嵌资产。
