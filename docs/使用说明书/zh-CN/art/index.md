# 美术设计稿

这一组图以 wunder 桌面版（本地 AI 工作台）为主线，同时覆盖 wunder 命令行（手工本地操作入口）。代码与真实渲染是事实来源，SVG 用于改稿、重构对照和实现验收；图与代码冲突时先核对实机，不用示意图替代当前实现。设计稿是设计与实现对照参考，不是产品界面；真实界面截图见[界面概览](/docs/zh-CN/surfaces/)。

- 打开[设计稿统一画廊](/docs/art/)，可浏览全部 16 张稿。源文件位于 `docs/wunder美术设计稿`，分为 `desktop/` 与 `cli/`。
- 画廊支持鼠标左键或触屏单指拖动平移，以及适宽、适窗、100%、缩放、前后翻页；方向键移动，`+/-` 缩放，`0` 重置，Esc 关闭。
- 本页可正常滚动查看全部设计稿；点击任意图片打开可缩放浏览器，支持拖动平移、滚轮缩放、适宽/适窗/100% 与前后翻页。无 JavaScript 时可打开原始 SVG。
- 每张图按“真实界面 → 功能结构 → 状态表现 → 尺寸与行为约束”组织。控件交互态与任务生命周期分开呈现，不把建议项画成实机状态。
- 桌面版的帮助手册内嵌的是真实界面截图（`ui-overview.png`），不内嵌本组 SVG；命令行稿也不进入桌面版内嵌手册。

## 维护方式

改完 SVG 后在本仓库根目录运行一次：

```bash
python scripts/sync_art.py
```

它会重建文档站：

1. 把 SVG 发布到 `web/docs/art`（桌面版）与 `web/docs/art/cli`（命令行），并复制统一画廊及 `art-viewer` 资产；发布版自动把应用图标内嵌为 data URI。

Web 端重建站点后即生效。桌面版帮助不再内嵌设计稿预览，只放一张真实界面截图：`crates/wunder-desktop/frontend/assets/help/art/ui-overview.png`。这张图不由本流程生成，需要更新时直接替换，桌面版重新编译后通过 `include_bytes!` 编进二进制。

桌面版新增或删除分页时，同步统一画廊 `docs/wunder美术设计稿/index.html` 中的稿件数据与本页章节即可，不涉及桌面版内嵌资产。

命令行新增或删除分页时，同步统一画廊稿件数据、本页章节与 `docs/wunder美术设计稿/cli/README.md` 即可，不涉及桌面版内嵌资产。

查看器共享实现位于 `docs/wunder美术设计稿/assets/art-viewer.js` 和 `art-viewer.css`；文档站只在美术页加载它们，动态导航时会清理旧实例。所有分页还应通过 XML、内部引用和 Edge 原始宽度渲染检查。
