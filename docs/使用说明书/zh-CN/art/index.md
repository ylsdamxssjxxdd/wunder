# 美术设计稿

这一组图以蛹（本地 AI 工作台）为主线，同时覆盖舵机（手工本地操作入口）。代码与真实渲染是事实来源，SVG 用于改稿、重构对照和实现验收；图与代码冲突时先核对实机，不用示意图替代当前实现。

- 打开[设计稿统一画廊](/docs/art/)，可浏览全部 16 张稿。源文件位于 `docs/wunder美术设计稿`，分为 `蛹/` 与 `舵机/`。
- 画廊支持鼠标左键或触屏单指拖动平移，以及适宽、适窗、100%、缩放、前后翻页；方向键移动，`+/-` 缩放，`0` 重置，Esc 关闭。
- 本页内嵌的大图也支持拖动。普通滚轮继续滚动文档，Ctrl/Command + 滚轮缩放图片；无 JavaScript 时可打开原始 SVG。
- 每张图按“真实界面 → 功能结构 → 状态表现 → 尺寸与行为约束”组织。控件交互态与任务生命周期分开呈现，不把建议项画成实机状态。
- 蛹的帮助手册另外内嵌位图预览，避免引入 SVG 渲染链；舵机稿不进入蛹内嵌手册。

## 维护方式

改完 SVG 后在本仓库根目录运行一次：

```bash
python scripts/sync_art.py
```

它会依次完成三件事：

1. 把蛹稿 SVG 渲染成 1200px PNG，写到 `frontend-slint/assets/help/art`（蛹内嵌用）。
2. 用这些 PNG 重建蛹的中英手册 JSON。
3. 重建文档站，把 SVG 发布到 `web/docs/art`（蛹）与 `web/docs/art/servo`（舵机），并复制统一画廊及 `art-viewer` 资产；发布版自动把应用图标内嵌为 data URI。

Web 端重建站点后即生效；蛹需要重新编译桌面程序，预览图通过 `include_bytes!` 编进二进制。

蛹新增或删除分页时，需要同步 `scripts/render_art_previews.py` 的 `SHEETS`、`scripts/build_help_manual.py` 的 `ART_TOPICS`、统一画廊 `docs/wunder美术设计稿/index.html` 中的稿件数据，以及本页章节。不要手改 `frontend-slint/assets/help/art` 里的 PNG。

舵机新增或删除分页时，同步统一画廊稿件数据、本页章节与 `docs/wunder美术设计稿/舵机/README.md` 即可，不涉及蛹内嵌资产。

查看器共享实现位于 `docs/wunder美术设计稿/assets/art-viewer.js` 和 `art-viewer.css`；文档站只在美术页加载它们，动态导航时会清理旧实例。所有分页还应通过 XML、内部引用和 Edge 原始宽度渲染检查。
