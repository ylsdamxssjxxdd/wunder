# 功能与能力速查

按使用场景列出 wunder 的主要能力，并标注每项能力对应的功能入口。

## 智能对话

位置：工作台（蜂窝或蜂巢）→ 左栏「新任务」按钮或工作区下的线程列表。

- 提问并获得智能回答
- 上传文件让智能体分析
- 让智能体执行各种任务（写代码、处理文件、搜索信息等）
- 查看对话历史和继续之前的会话

**相关参考**

- [会话状态说明](/docs/zh-CN/reference/stream-events/)
- [提示词与个性化](/docs/zh-CN/reference/prompt-templates/)

## 工作目录

位置：工作台 → 左栏工作区下方的「工作目录」区。

- 上传文档、图片、音频等文件供智能体使用
- 下载智能体生成的文件
- 浏览和管理属于自己的唯一云端目录
- 查看智能体工作过程中产生的文件

**相关参考**

- [工作区路由与文件管理](/docs/zh-CN/reference/workspace-routing/)

## 智能体设置

位置：工作台 → 左栏底部「设置」→「智能体」。

每个用户只有**一个**智能体实例，由管理侧预设 1:1 绑定生成。用户侧没有创建、删除、切换或排序智能体的入口。

- 查看当前智能体实例与绑定的预设
- 修改预设允许自定义的字段（如默认模型、审批模式、工具集合）
- 设置智能体的回答风格（提示词模板）
- 管理智能体的长期记忆

**相关参考**

- [提示词与个性化](/docs/zh-CN/reference/prompt-templates/)
- [工具体系概念](/docs/zh-CN/concepts/tools/)

## 工具与技能

位置：工作台 → 左栏底部「设置」→「工具」。用户侧只做查看与开关，工具清单由管理侧维护。

- 查看可用工具列表
- 配置技能（预设的能力包）
- 添加知识库（让智能体参考用户的专属资料）

内置工具覆盖：

- 文件操作：读取、写入、搜索文件
- 网络操作：搜索、抓取网页内容
- 代码操作：执行命令、编写代码
- 系统操作：截图、获取系统状态
- 更多能力通过 MCP 扩展

**相关参考**

- [工具体系概念](/docs/zh-CN/concepts/tools/)
- [提示词与技能概念](/docs/zh-CN/concepts/prompt-and-skills/)

## 渠道接入

位置：舰桥 → "渠道管理"。

- 绑定飞书/企业微信/微信/QQ 等账号
- 让外部平台的用户也能使用智能体
- 查看渠道运行状态和消息日志
- 排查渠道相关问题

当组织成员习惯在飞书、微信里沟通时，用渠道接入让他们不用换工具就能使用智能体。

**相关参考**

- [渠道管理指南](/docs/zh-CN/ops/channel-runtime/)
- [舰桥面板指南](/docs/zh-CN/reference/admin-panels/)

## 定时任务

位置：工作台 → 左栏底部「设置」→「定时任务」。

- 创建定时执行的任务
- 查看任务执行历史
- 管理、暂停、删除定时任务

适合周期性工作，比如每天定时汇总报告、定时检查系统状态。

## 系统设置

位置：工作台 → 左栏底部「设置」。

- 修改系统语言
- 配置连接的服务地址
- 管理个人账户信息
- 查看使用统计和额度余额

**相关参考**

- [系统设置参考](/docs/zh-CN/reference/config/)

## 舰桥功能（管理员专用）

位置：浏览器访问舰桥地址。主要面板：

- 系统设置：全局配置
- 用户管理：用户账户、额度账户
- 单位管理：组织架构
- 模型配置：可选用的 AI 模型
- 工具管理：可用工具列表
- 渠道监控：外部渠道状态
- 性能监控：系统运行状态

**相关参考**

- [舰桥面板指南](/docs/zh-CN/reference/admin-panels/)
- [系统设置参考](/docs/zh-CN/reference/config/)

## 按需求快速定位

| 我想... | 去哪里 |
|---------|--------|
| 开始一个对话 | 左栏「新任务」→ 直接输入 |
| 上传文件让智能体分析 | 左栏工作目录区点上传或拖拽文件，也可在输入区加附件 |
| 查看智能体生成的文件 | 左栏工作目录区 |
| 定制智能体的风格 | 左栏底部「设置」→ 智能体 → 提示词模板 |
| 创建定时任务 | 左栏底部「设置」→ 定时任务 → 创建任务 |
| 管理用户（管理员） | 舰桥 → 用户管理 |
| 配置渠道（管理员） | 舰桥 → 渠道管理 |
