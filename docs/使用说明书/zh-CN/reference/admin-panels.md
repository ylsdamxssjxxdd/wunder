# 管理端面板指南

管理端是系统管理员的工作台，用于配置系统、管理用户、监控运行状态。这页帮用户快速定位各面板的功能。

## 系统分组

这个分组聚焦全局管理：

### 内部状态

查看系统运行状态，包括：
- 活跃会话数
- 系统负载
- 关键组件状态

### 系统设置

配置全局参数，包括：
- 服务地址和端口
- 安全设置
- 存储设置
- 工具开关

### 单位管理

管理组织架构：
- 创建和管理单位
- 单位层级关系
- 单位成员管理

### 用户管理

管理用户账户：
- 用户列表查看
- 创建新用户
- 编辑用户信息
- 额度账户管理（发放、扣除、设置余额）

**用户设置中的 额度操作**：
- **直接设置余额**：覆盖当前余额，适合修正账面值
- **发放额度**：增加余额，记录累计获得
- **扣除额度**：减少余额，记录累计消耗
- 管理员账户不参与 额度余额限制

### 外链管理

管理外部系统接入：
- 查看接入配置
- 管理认证密钥

### 渠道监控

监控外部渠道运行状态：
- 渠道账号状态
- 消息收发统计
- 异常告警

## 智能体分组

这个分组聚焦智能体能力配置：

### 模型配置

管理可用的 AI 模型：
- 添加新模型（填写 API 密钥、接口地址）
- 配置模型参数
- 设定默认模型

### 线程管理

查看和管理活跃线程：
- 线程状态查看
- 强制取消线程
- 线程详情查看

### 预设智能体

管理预设智能体模板：
- 创建预设智能体（供用户选用）
- 配置预设智能体的工具和模型
- 同步到用户侧

### 工具管理

管理可用工具：
- 查看内置工具列表
- 配置 MCP 外部工具
- 设置工具权限

### 系统提示词

管理全局提示词模板：
- 查看和编辑系统模板
- 切换默认模板包
- 创建新的模板包

## 调试分组

这个分组聚焦工程验证和性能评估：

### 吞吐量测试

选择模型、并发数和输出长度，每次测试一个组合并同时发起指定数量的请求。输出保留常用档位，也可直接输入范围内的整数；管理员页面使用固定默认输入长度，历史快照仍显示 API 实测输入用量。右侧显示聚合后的实际输入输出、首字延迟、生成速度和总耗时；历史曲线按模型、并发数和输出长度分组。

支持的推理引擎会接收定长输出参数，其他接口可能提前结束；实际用量和结束原因会在详情中保留。测试不创建会话或线程日志，仅保存最近 50 次性能摘要。勾选历史记录即可按输入长度或时间比较性能曲线，也可复用配置或导出所选数据。

虚拟模型可在模型配置选择快 / 中 / 慢，默认快：预填充 2000 / 500 / 100 Token/s，思考与生成 200 / 50 / 10 Token/s。随机模拟回复与吞吐模拟都会先思考再生成内容，回放日志在配置的能力与预算内使用原有思考内容。吞吐测试的思考量默认占输出总数 1/4，可通过思考开关与预算调整，模拟记录按速度单独标记和分组。

### 性能测试

测试响应性能：
- 单请求延迟测量

### 蜂群测试

测试蜂群协作能力：

### 能力评估

评估智能体能力水平：

### 调试面板

实时调试工具：

- 错误排查

### LSP

## 常用操作流程

### 新用户加入

流程：
1. 用户管理 → 创建用户
2. 设置用户名、密码、所属单位
3. 根据需要发放额度
4. 用户即可登录使用

### 配置新渠道

流程：
1. 渠道监控 → 添加渠道账号
2. 填写渠道类型和凭证
3. 配置 Webhook 地址（如需要）
4. 查看账号状态确认正常

### 调整系统设置

流程：
1. 系统设置 → 找到对应配置项
2. 修改设置值
3. 保存（通常立即生效）
4. 在内部状态确认效果

### 处理异常会话

流程：
1. 线程管理 → 查看异常线程
2. 查看线程详情和状态
3. 如需终止，点击取消
4. 查看相关日志定位问题

## 管理端访问方式

管理端通常通过独立地址访问：
- 浏览器打开管理端 URL
- 使用管理员账户登录
- 登录后即可使用各管理面板

具体地址由部署时确定，请询问系统部署人员或查看部署文档。

## 安全提醒

管理端拥有系统最高权限，请注意：

- 只有授权的管理员才能访问
- 管理员账户密码要足够复杂
- 定期更换管理员密码
- 操作前确认影响范围，避免误操作
- 重要操作做好记录

### 模拟模型能力

模型配置选择虚拟模型后，可设置最大上下文、最大输出、视觉、听觉、思考和工具能力。上下文与输出留空时分别为 128k / 4k；输入（包括工具定义）加输出预算超过窗口，会报告上下文超限。关闭视觉或听觉后，相应媒体请求报错。图片、音频可分别设置每项 token 数，仅模拟用量和耗时，不识别内容。

回放时使用“工具调用方式”：`function_call` 走原生工具通道，`tool_call` 走文本协议，`freeform_call` 根据 API 模式使用原生或文本回退。工具名称与参数直接来自日志，无需手填；工具执行仍遵守权限和审批，结果返回后继续回放下一模型轮次。日志耗尽会报错，不重复执行旧调用。合成回复不主动调用工具。输出过长会标记长度终止，不完整的工具参数不会执行；思考能力和预算也作用于吞吐测试。
