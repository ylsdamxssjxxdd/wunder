# 工作区路由与文件管理

每个用户只有一个云端目录。

## 一个用户一个云端目录

隔离只有一层：按用户。每个用户的文件都落在**属于自己的唯一云端目录**里，由服务端在数据根下按用户划分。

| 约定 | 说明 |
|------|------|
| **唯一** | 同一时刻只有一个工作区目录；不会因为多开线程或子智能体而新增目录 |
| **固定** | 用户不能新增、删除或更换目录，也不能绑定本机文件夹 |
| **隔离** | 路径校验以用户根为界，越界读写被拒绝 |
| **持久** | 工作区是持久存储，不会自动清理 |

## 路由规则

`/wunder/workspace*` 的请求按以下顺序解析：

1. 请求带着已登录用户的身份
2. 服务端解析到该用户的工作区根
3. 在该根下按请求里的相对路径定位条目

几点补充：

- **容器参数已收敛**：历史接口里的 `container_id` 不再决定目录，服务端统一按用户根解析；过渡期仍接受该参数，但传 0 还是 1 结果相同，前端不再提供容器选择。
- **不再按智能体派生根**：`agent_id` 只影响会话与配置绑定，不参与目录派生。
- **子智能体不另开目录**：子智能体是主智能体临时创建的工作单元，与主智能体共用同一个用户目录。

## 路径约定

- 接口收发的都是**工作区相对路径**，例如 `docs/notes.md`
- 根目录用空字符串表示
- 不要传本机绝对路径，也不要把服务端绝对路径写进前端展示
- 名称非法或越界的请求会被直接拒绝，而不是被静默重定向

## 工作区与临时目录

| | 工作区 | 临时目录 |
|--|--------|----------|
| **用途** | 长期存放文件与任务产物 | 上传下载中转、文档转换中间文件 |
| **生命周期** | 持久，不自动清理 | 可能被定期清理 |
| **路径** | 工作区相对路径 | 单独的中转命名空间 |

需要长期保存的文件放工作区，中转文件放临时目录。

## 用量统计

`GET /wunder/workspace/stats` 返回裸对象，字段包括文件数、目录数、已用字节、是否被截断和最近修改文件：

- 统计走有界遍历，目录很大时会提前结束，`truncated` 为真表示计数是下界
- `quota_bytes` 为 `null` 表示未配置配额，此时界面只显示已用量，不显示配额分母
- 欢迎页的工作目录概览卡片与左栏底部用量条共用这份数据

## 文件管理要点

- **浏览**：目录懒加载，点开才拉子目录；大目录分页，条目虚拟滚动
- **上传**：可以点工具栏上传，也可以把文件拖到文件树区域；上传有并发上限，可取消与重试
- **预览与编辑**：文本、图片、Office、流程图都有对应的预览或在线编辑弹层
- **引用到聊天**：文件行菜单选「引用到聊天」，把文件带进输入区，时间线里可点击回定位
- **批量与打包**：多选后可批量删除或打包下载
- **高危险操作**：删除、清空目录需要二次确认；前端确认不替代服务端鉴权

## 上传与文件类型

| 类型 | 处理 |
|------|------|
| 文档（PDF、Word、Markdown 等） | 自动转换为文本供智能体分析 |
| 图片（PNG、JPG 等） | 智能体可以直接查看和分析 |
| 音频（MP3、WAV 等） | 自动转写为文字 |
| 视频（MP4 等） | 按设定帧率提取画面分析 |
| 代码文件 | 各种编程语言文件，智能体可直接读取 |
| 其他 | 按原样存储，智能体可尝试读取 |

部分文件上传后需要先处理（文档转文字、音频转写等），处理完成前发送按钮会被禁用。
