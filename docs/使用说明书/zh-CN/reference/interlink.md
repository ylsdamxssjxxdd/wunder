# 三端互通

三端互通把蜂巢（web）、蜂窝（desktop）、舵机（cli）连成一套：**统一在线状态 + 跨端工作区互见 + 双向远程控制**。本地设备不开公网入口，所有流量经舰体中继。

## 三端与前提

| 名称 | 形态 | 定位 |
|------|------|------|
| 蜂巢 | web | 云端 AI 工作台，随舰体提供，浏览器访问 |
| 蜂窝 | desktop | 本地 AI 工作台，桌面形态，可直接访问本机文件 |
| 舵机 | cli | 手工本地操作入口，命令行形态 |

前提：

1. 三端共享 `wunder-runtime` 引擎与 `wunder-core` 契约。
2. 本地已通过既有 cloud 连接方案登录舰体，持有 `wund_<token>` + `device_id`。
3. 舰体是账号、设备、额度与策略的唯一权威。

## 四条能力

| 编号 | 能力 | 说明 |
|------|------|------|
| R1 | 统一在线状态 | 舰体建立跨端节点目录，三端统一状态模型 `online` / `away` / `busy` / `reconnecting` / `offline`，秒级（本地）/ 准实时（网页）精度 |
| R2 | 工作区互见 | 本地工作区以**影子投影**出现在蜂巢，投影的是元数据摘要（线程目录、目录树摘要、定时任务、用量）；**文件内容不镜像**，按用户操作经互通隧道按需拉取 |
| R3 | 云端控制本地 | 蜂巢可对在线本地节点发起分级操作（查询 / 会话控制 / 工作区写 / 工具执行），敏感操作经本地**人在回路审批**，全程审计 |
| R4 | 本地控制云端 | 蜂窝/舵机把云端当作对称节点——浏览云端工作区、向云端线程发消息、读取线程事件流；舵机提供脚本化命令组 |

统一状态模型：

| 状态 | 语义 |
|------|------|
| `online` | 在线且空闲 |
| `busy` | 在线且执行中 |
| `away` | 在线但闲置 |
| `reconnecting` | 断线恢复中 |
| `offline` | 离线 |

## 怎么用

### 蜂窝（desktop）

| 入口 | 说明 |
|------|------|
| 设置页「设备互通」类目 | 隧道状态、设备表、云端工作区浏览 |
| 远端命令审批弹窗 | 2s 轮询 pending 队列，批准 / 拒绝 |
| 侧栏线程来源徽标 | 云端 / 设备 |
| 隧道客户端 | 进程启动即挂 |

### 蜂巢（web）

| 入口 | 说明 |
|------|------|
| 侧栏 | 以「设备即工作区」呈现：设备以侧栏工作区行体现，目录随线程点击归位 |
| 「云端/设备」下拉切换器 | 已移除 |

### 舵机（cli）

| 入口 | 说明 |
|------|------|
| `cloud` 子命令组 | `devices` / `ws` / `send` / `watch` / `audit` / `approve` |
| `cloud status` | 整合四段：互通隧道、待决审批、其他设备、云端工作区用量 |
| `cloud watch` | 帧型为 `snapshot` / `delta` / `command` / `error` / `close` |

## 安全边界

| 边界 | 含义 |
|------|------|
| 零公网入口 | 反向隧道：本地只出站长连接，不开监听端口，控制流复用已建链路下发 |
| 最小能力 | 每类远程操作是声明式能力，默认只开只读 |
| 显式授权 | 写与执行类必须本地用户授权，管理员可在舰桥再收敛 |
| 逐级审批 | L0–L3 风险分层，见下表 |
| 完整审计 | 每次远程操作成链可查 |
| 一键关停 | kill switch 由用户掌握 |

风险分层：

| 级别 | 覆盖的操作 | 审批 |
|------|------|------|
| L0 只读 | `node.summary` / `shadow.refresh` / `workspace.list\|search\|stat\|read` / `threads.list\|get` | 免审批 |
| L0+ | `workspace.read:binary` | 免审批 + 审计 |
| L1 会话 | `thread.create` / `thread.message` / `thread.cancel` / `thread.answer` | 默认需审批，可降为免审批 |
| L2 工作区写 | `workspace.write\|mkdir\|move\|copy\|delete` | 强制审批，不可降 |
| L3 执行 | `tool.exec`（白名单命令） / `agent.spawn` | 强制审批 + 管理员默认禁用，可开 |

两条最该记住的：

- **L3 默认关闭**：`tool.exec` / `agent.spawn` 默认不在设备能力集；审批永不记忆；执行结果只回摘要。
- **L2 写先备份**：写操作先备份到 `工作区/.interlink_backup/<command_id>/`（保留最近 50 代），结果给出前后 SHA256。

## 非目标

- 本地 / 云端线程**不合并**，也互不可见。互通是远程操作，不是数据同步；远程线程在对方侧始终以「远端」标识存在。
- 不做工作区文件全量镜像与双向同步，只有元数据投影 + 按需拉取。
- 不做图形化远控，控制粒度止于引擎与文件 API。
- 不做 NAT 穿透打洞，所有流量经舰体中继。
- 蜂窝与舵机之间不直接互通，本地互访一律经舰体中转。

## 代价

| 指标 | 实测 |
|------|------|
| 空闲隧道 CPU | 单核增量 0.114% |
| 空闲窗口内存 | 工作集增长 0.18 MB（建链一次性 +4.7 MB 另记） |

数字来自 `scripts/interlink-bench/measure-idle.ps1` 的同进程两段法采样（baseline / tunnel 各采样一段测增量）。
