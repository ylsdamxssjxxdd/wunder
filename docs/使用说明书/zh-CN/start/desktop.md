# 蜂窝（desktop）入门

蜂窝（desktop）是 wunder 的桌面版，也是默认使用方式：一个**本地 AI 工作台**。下载安装即可使用，不需要先部署舰体（server），打开就能把目标交给智能体。

## 适用场景

| 场景 | 选蜂窝 |
|------|-----------|
| 想直接开始用，不想先部署服务 | ✅ |
| 需要操作本地文件、窗口、浏览器 | ✅ |
| 更习惯图形界面 | ✅ |
| 后面可能接远端，但现在先跑起来 | ✅ |
| 需要多用户治理和管理员后台 | ❌ 选舰体（server） |

## 界面结构

蜂窝是左右两栏布局：

- 左栏（固定 240px）：新任务、搜索、工作区与线程树、工作目录（文件树 + 工具栏 + 用量条）、底部设置
- 右栏：欢迎页或聊天页（顶栏 + 时间线 + 输入区）

文件预览、在线编辑等以浮层弹出，不改变两栏结构。每个用户只有一个智能体实例和一个固定的工作目录。

## 5 步上手

### 1. 下载安装

从 Releases 下载对应系统的安装包，安装后启动。

### 2. 首次启动

启动后先显示轻量启动页，再准备本地工作目录、配置和会话。窗口出现不代表会话已就绪；进入工作台后即可操作。首次启动或设备较慢时，准备时间可能更长。如果启动页提示失败，可点击重试或重新加载。

### 3. 配置模型

进入「系统设置」→「模型配置」，填入：

- API Key
- 接口地址
- 模型名称

保存前建议先点「测试连接」确认能用。

### 4. 完善账号资料

首次登录后建议：

- 去「我的概况 → 编辑资料」修改用户名或邮箱
- 如果是长期使用，顺便设置新的登录密码

### 5. 发起第一次对话

回到聊天页，输入：

```
帮我列出当前工作目录的文件
```

你会看到模型开始执行 → 工具逐步工作 → 最终回复落到聊天区。

## 两个常见交互约束

### 运行中不能新建线程

当前智能体还在运行时，「新建线程」按钮会被禁用。这是正常保护，等它完成或先停止当前会话再新建。

### 子智能体运行时的提示

任务里派生了子智能体时，聊天区会提示当前仍在工作的子运行，方便判断任务是否真的结束。

## 重置工作状态

会话、子智能体或工作区状态混乱时，用「系统设置」里的「一键重置工作状态」。

它会清理运行中的状态，但不会删除技能、知识库等长期资产。

## 本地模式额外能力

蜂窝本地模式下，聊天区还会看到：

- 🎤 麦克风按钮（语音输入）
- 📷 截图按钮（截屏分析）

是否可用取决于当前机器权限。

## 查阅帮助手册

左栏底部「设置」→ 帮助，可以直接在应用内查阅文档。
