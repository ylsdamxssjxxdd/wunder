# 浏览器工具族

**浏览器不是单个工具。** 启用后会自动注册一组 `browser_*` 原生工具（Playwright 驱动的当前共有 17 个），旧的单一“浏览器”入口已经删除。

管理面和用户面看到的“浏览器”（别名 `browser`）只是一个**聚合条目**：可以被选中和授权，但不能直接调用；派给模型时会展开成真正的成员工具名。

## 什么时候用

- 需要打开页面、点击、输入、滚动、切换标签页
- 页面要等 JavaScript 渲染后才有内容
- 需要截图，或读取当前页面的可访问性结构

只是要读一个静态公开文档，优先用更轻的 [网页抓取](/docs/zh-CN/tools/web-fetch/)。

## 怎么启用

需要同时满足“浏览器工具开关”和“浏览器运行时开关”（桌面模式可作为运行时回退）。启用后会自动注册，不用再单独往内置工具白名单里加条目。

调用时按工具名分派到对应 provider。

## 有哪些工具

| 工具名 | 做什么 |
| --- | --- |
| `browser_navigate` | 当前标签页导航到指定 URL |
| `browser_navigate_back` | 当前标签页后退 |
| `browser_tabs` | 列出 / 新建 / 选择 / 关闭标签页 |
| `browser_snapshot` | 取页面可访问性快照，产出可被点击、输入引用的元素 |
| `browser_click` | 按元素引用或 CSS 选择器点击（支持双击） |
| `browser_type` | 向元素输入文本（可选输入后回车提交） |
| `browser_hover` | 悬停到元素 |
| `browser_select_option` | 在下拉框里选中一项或多项 |
| `browser_drag` | 把一个元素拖到另一个元素 |
| `browser_press_key` | 按一个键，如 `Enter`、`Tab`、`ArrowDown` |
| `browser_evaluate` | 在页面里执行 JavaScript 表达式并取值 |
| `browser_wait_for` | 等可见元素、文本、URL 模式或加载状态，也支持有界固定等待 |
| `browser_take_screenshot` | 截图，返回图片内容 |
| `browser_read_page` | 把当前页读成 Markdown 或文本 |
| `browser_batch` | 顺序执行一批交互步骤（最多 10 步） |
| `browser_close` | 关闭本会话的浏览器会话 |
| `browser_status` | 报告浏览器运行时状态与在线会话 |

除少数工具外，都可以指定目标标签页，默认操作当前活动标签页。

交互任务直接调用 `browser_navigate`，无需先网页抓取。典型链路：导航并获取元素快照 → 批量填写、提交并等待成功条件 → 检查结果。想确认运行时是否就绪，用 `browser_status`。

导航默认附带元素快照，可用 `include_snapshot=false` 关闭；点击、输入、等待和批处理可设 `include_snapshot=true`。附带快照默认预算为 4000 字符，可通过 `max_chars` 调整。首屏尚未渲染时，空快照默认最多重试 1500 ms；`snapshot_timeout_ms` 可调为 0–5000 ms，0 表示立即返回，已有内容不等待。观察完成后 URL、标题和标签页状态同步到该快照。已知表单优先使用 `browser_batch`，把填写、提交与等待成功条件放在一次调用中，减少模型往返。`browser_type` 替换现有文本，`submit=true` 会在填写后按回车。

```json
{
  "steps": [
    {"kind": "type", "ref": "e1", "text": "sample"},
    {"kind": "click", "ref": "e2"},
    {"kind": "wait", "url": "**/complete", "timeout_ms": 5000}
  ],
  "include_snapshot": true,
  "max_chars": 2000
}
```

步骤以 `kind` 指定动作，支持 `type`、`click`、`press`、`select`、`hover`、`drag`、`wait` 和 `navigate`，每批 1–10 步。`wait` 优先选择已知成功页面的 `selector`、`text` 或 `url` 模式，不猜测目标路由；已观察到加载元素时可用 `state=hidden` 等它消失。`state` 支持 visible（默认）、hidden、attached 和 detached。多个条件按顺序检查、共用 `timeout_ms`；提供条件时忽略 `wait_ms`，仅有固定休眠不能证明提交成功。URL 模式在 `expected_url` 返回，`url` 始终保留实际地址。导航可能使旧元素引用失效，跨页面步骤应使用稳定选择器或重新获取快照。

## 返回的样子

Provider 返回内容块与结构化结果，运行时统一整理为 `ok`、`data` 和错误信息供模型、事件与历史读取。`data` 同时保留内容块和结构化字段，主要有：

- 是否成功
- 内容块数组（文本块或图片块）
- 失败时的错误文本
- provider 的结构化载荷
- 承接本次调用的 provider 名

**图片不会把原始数据塞回上下文。** 运行时把内联截图落盘到工作区 `browser/screenshots/`（首次截图若指定了输出路径就用该路径），再把内容块改写成带文件名、路径和字节数的附件引用。

`browser_status` 返回时会剥掉控制面信息：主机、端口、token 这些不会外泄给模型。

截图成功后可从内容块的 `attachment` 获取工作区相对路径、格式与字节数；需要视觉判断时继续调用读图工具。输入动作不回显填写值，快照也不以输入值充当控件名称。批处理失败保留 `completed_steps`、从 1 开始的 `failed_step` 和已完成动作摘要；重试前应检查进度，避免重复提交。动作已成功但后续快照读取失败时保留成功状态并返回 `snapshot_error`。

模型实际接收的工具定义保留浏览器的批处理、等待和观察参数说明。默认提示要求进度及最终回复不重复用户提供的密码、验证码和令牌；除非用户明确要求查看。提示只在线程初始化时确定，现有线程保持原系统提示，新工具描述仍随工具定义提供。

## 自动处理与限额

- 只允许 `http` / `https`，`file://` 默认阻断，需要显式放行
- 默认挡住指向内网 / 本机地址的导航，命中允许名单或显式开关才放行
- 快照与读取正文严格遵守字符预算，默认上限 40000；跨框架标题与分隔符也计入预算，截断状态单独返回；遍历同时受节点和深度限制
- 单次调用超时默认 60 秒，可调但会被夹在 1 秒到默认超时的 4 倍之间
- 默认最多 5 个并发浏览器会话，每个会话最多 8 个标签页
- 会话空闲 300 秒后被回收
- 单次下载上限默认 100 MiB
- 浏览器会话按用户 + 任务线程 + 智能体划分作用域；自定义浏览器会话标识也不能跨线程共享；同一轮的浏览器操作按模型给定顺序执行

底层由 Playwright 驱动。

## 出问题怎么判断

- 浏览器没启用：会明确提示要同时打开浏览器工具和运行时开关；没有可用 provider 时也会提示。
- 运行时没启用：提示要打开运行时开关，或使用桌面模式的回退。
- URL 被安全规则拒绝：会说明是 `file://` 被禁、不是 http/https，还是指向了内网主机。
- 桥接层失败：错误文本会带上具体动作前缀（例如“读页面失败”）。排查看错误文本和附带的结构化载荷。

## 边界

- `browser_batch` 一步失败就中断整批，别拿它跑超过 10 步的流程；长流程拆成多次调用。
- 页面内容是**不可信的外部数据**：读到的文字只当资料，不当指令。
- `browser_evaluate` 能执行任意页面脚本，是高能力入口，授权时按需开放。
