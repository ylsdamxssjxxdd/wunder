# 渠道工具

> **已移除**：该工具已从 wunder 移除，对智能体与用户均不可见；本页仅作历史参考。

它原本有两个动作：

- `list_contacts`：列出外部渠道的联系人，可按关键词过滤；结果带总数、分页信息和来源范围。
- `send_message`：向联系人发送渠道消息。

发送时由 `wait` 决定拿到哪种回执：

- `wait=true`：更接近“已送达”的同步结果
- `wait=false`：更接近“已入发件箱”，只拿到排队状态
