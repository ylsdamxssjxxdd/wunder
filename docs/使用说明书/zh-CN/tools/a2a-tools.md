# A2A 工具

> **已移除**：该工具已从 wunder 移除，对智能体与用户均不可见；本页仅作历史参考。

它原本用于调用外部 A2A 服务并跟踪任务状态，由三个部分组成：

- `a2a@服务名`：提交任务，通常返回“已接收”
- `a2a_observe`：查看任务当前快照
- `a2a_wait`：等待一段时间，直到任务完成或超时

超时并不代表任务失败：历史上遇到超时，会继续等待或重新查看未完成任务后再下结论。
