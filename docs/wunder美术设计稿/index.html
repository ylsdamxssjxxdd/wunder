不用滚动条，直接拖动画布

点击任一设计稿进入大图浏览器。画布可以超出视口，但不会无限拖丢。

  1. 按住鼠标左键拖动平移，触屏单指同样可用。
  2. 适宽、适窗、100% 随时切换；放大后查看控件细节。
  3. 方向键移动，+ / − 缩放，0 重置，Esc 关闭。

文档站内嵌的大图也支持拖动；普通滚轮继续滚动文档，Ctrl/⌘ + 滚轮才缩放图片。

大图浏览操作

拖动 / 单指拖动平移画布；指针捕获让拖出图片后仍能完成操作。
滚轮 / Ctrl + 滚轮画廊滚轮缩放；文档内嵌图需 Ctrl/⌘，避免误阻页面滚动。
适窗 / 适宽 / 100%按任务切换整体结构、横向内容与真实像素。
PageUp / PageDown画廊内前后切换；工具栏始终保留原始 SVG 入口。
事实来源：frontend-slint/ui 与 crates/wunder-cli/tui。建议项不与实机状态混画。
