# wunder 美术设计稿

wunder 多形态工作台的两套界面基线，按形态分目录。各稿以「当前实现」为事实基线，用于改稿、重构对照、实现验收和新人理解组件边界，不是营销稿。

| 目录 | 形态 | 基线 |
| --- | --- | --- |
| [`蛹/`](蛹/README.md) | 本地 AI 工作台（desktop） | `frontend-slint/` · Slint 窗口 UI · 10 张稿 |
| [`舵机/`](舵机/README.md) | 手工本地操作入口（cli） | `crates/wunder-cli/tui/` · 终端 TUI · 6 张稿 |

两套稿共享同一条设计语言：语义由「强调色 + 字重」承载、中性色不跟随强调色、状态与文案由运行时投影、前端不推导状态、无障碍与降级是硬性要求。差异在于画布——蛹按逻辑像素排版，舵机按终端行列预算。

## 使用

1. 各形态稿的入口是各自目录里的 `README.md`；蛹另有 `蛹/index.html` 画廊索引。
2. 改完 SVG 后统一运行 `python scripts/sync_art.py`：刷新文档站与蛹内嵌预览图。
3. 事实来源以各稿 README 的清单为准；稿与代码冲突时，先核对实机再决定改哪边。
