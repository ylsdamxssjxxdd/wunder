# wunder 技术说明书

## 文档定位

本目录是 wunder 的**工程执行手册**，覆盖五类内容：

- 系统分层，以及术语在代码里指什么
- 目录与模块职责、改动落点
- 一条请求在代码里的流转与轮次语义
- 部署、启动、配置与验证
- 故障定位入口与验收口径

## 读者

- **后端开发**：运行时、存储、接口、扩展路径
- **前端/桌面开发**：实时事件、投影契约、状态恢复、本地 façade
- **运维/集成**：部署方式、配置项、网关、渠道、观测
- **评审/验收**：系统边界、运行链路、风险点、验收标准

## 体例与事实口径

- **一切以代码为准**：技术事实都给出仓库相对路径，关键处带 `文件:行号`。行号会漂移，路径与模块职责不漂移；对不上时以代码为准并回来修文档。
- 只在确实不存在时写「当前未实现」；不用「大约」「应该」掩盖没核实的东西。
- 示例值一律中性占位（`<user>`、`/path/to/workspace`、`https://example.com`），不出现真实身份、密钥或绝对路径。
- 涉及列表、日志、面板的章节必须写清分页/限量/有界语义。
- 蜂群编排（蜂群工具、蜂房、编排态、team run、蜂群包）已从引擎与调度面移除，**协作形态只有子智能体**；UI 与文案残留集中在 09 §11，不在其它章节复述历史结构。
- Electron / Tauri 前端壳停止维护：文档不把它们写成可用能力，也不把「停止维护前端壳」写成「停止维护蛹后端」。
