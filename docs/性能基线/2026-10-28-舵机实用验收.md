# 舵机真实交互验收（2026-10-28）

## 范围与方法

直接运行 `target/debug/wunder-cli.exe`，通过 Windows 11 ConPTY 输入按键、粘贴文本、调整终端宽高；使用独立用户目录、工作区与 SQLite，连接已有配置中的真实模型，不更改日常用户配置。

实际检查的是程序产生的 ANSI 终端屏幕，按屏幕单元格和颜色还原图像后逐张查看，并非原生终端窗口的像素截图。原始图像、流日志和临时配置不入库；真实模型凭据在验收后从隔离配置中清理。

## 本次发现与修复

1. 内联终端保留初始 viewport 高度：普通自动尺寸刷新不能更新构造时的行数。收到尺寸事件后重建匹配当前高度的内联终端，避免缩小再放大后输入区悬空。
2. 工具调用阶段曾创建假的助手进度消息。移除该占位，保留真实工具卡片和已产生的助手正文。
3. 取消请求可能先发送错误，再发送取消终态，最后关闭 stream。原始失败在同一 stream 中保持有效，避免关闭时重复追加空输出错误；下一条 stream 独立重置状态。
