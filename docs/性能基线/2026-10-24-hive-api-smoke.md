# 蜂巢 API 测试驱动首次验收

2026-10-24，独立 Docker Compose 栈实测 11/11 场景通过，失败 0；包括登录、目录/空聊天、流式、慢消费、取消后继续、排队调序撤回、双用户并发、权限隔离、工作区分页、大聊天打开、正常重启恢复。结束后该测试栈容器与数据库卷已清理，没有重启已有服务。

本次使用既有 Linux release 舰体二进制，SHA256 及镜像身份见[原始报告](2026-10-24-hive-api-smoke.json)。未为本次重编译舰体，不能据此声称当前工作区源码全部验收；执行时有其他 Rust 编译负载。这是 smoke 链路验收，每场景只有一次，不是稳定 P95 或优化效果结论。

受控模型首块约 8.27 ms、输出持续约 58.87 ms；首字/终态的其余耗时说明值得继续检查准入、上下文准备、数据库与收尾链路，本次不据此断定某一函数是瓶颈。

大线程实际为 100 用户轮次、10,000 模型请求、7,954 工具调用、17,954 模型动作，存储快照约 189 MB，生成约 135 秒。生成时间与聊天读取分别计时。此负载与蛹严格 100×100 动作不同。

另对登录和会话目录跑了 daily：每场景预热 1 次、正式采样 10 次，并重新创建独立栈验证 `--baseline` 比较流程；正确性与退化门禁均通过。完整套件的稳定 daily/release 基线仍需在无编译争用的固定机器建立。
