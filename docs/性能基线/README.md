# 性能基线目录

本目录保存性能优化、压测、回归防护相关的前后对比报告。历史「性能标准」与「性能评分体系」文档已从当前工作副本移除，现行口径以本目录的模板与既有报告为准。

三种形态（桌面版、云端版/服务端、命令行）的评分报告分别独立归档，不可跨形态相加；单项专项报告仍按本文模板保存，不要求每次都覆盖全部场景。

## 命名

- 报告：`YYYY-MM-DD-<scope>-<topic>.md`
- 原始资料：`assets/YYYY-MM-DD-<scope>-<topic>-<kind>.<ext>`

`scope` 使用简短范围，如 `backend`、`frontend`、`docker`、`runtime`、`workspace`、`web`。
