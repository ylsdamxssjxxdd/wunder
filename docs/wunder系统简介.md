# wunder 心舰简介

> 前端是温暖的蜂巢，后端是庞大的飞船。

wunder（心舰）是一个**智能体调度平台**：把目标交给智能体，它把目标拆成任务，在带工具的执行环境里一步步做完，最后交付结果。

它和常见的问答式 AI 不是一类东西。问答式 AI 的产出是一段文字；wunder 的产出是做完的事：写进工作区的文件、执行过的命令、改好的代码、发出去的消息、设好的定时任务。过程有事件流可以看，高风险动作有审批把着，断了线能恢复现场。

## 上手方式：蜂窝（desktop）

**蜂窝（desktop）是 wunder 的桌面版，也是主推的应用：一个本地 AI 工作台。** 个人用户下载安装即可使用，不需要先部署任何服务，打开就能把目标交给智能体。

蜂窝在本地运行：Rust + Slint 原生界面，启动后在同一进程内直接调用后端，不经本机 HTTP。SQLite 存储，兼容目标是 Windows 7 32 位。它可以操作本地文件、窗口和浏览器，也可以在需要时连接远端服务。

## 核心概念

```text
心舰
├─ 用户
│  ├─ 智能体
│  │  └─ 线程
│  └─ 工作区
└─ ...
```

- 用户：资源与数据的归属主体，相互隔离，每个用户只有唯一智能体实例。
- 智能体：具体干活的角色，有自己的模型配置、工具集、知识库和长期记忆。由管理侧预设 1:1 绑定生成，用户侧没有创建、删除、切换或排序的入口。
- 工作区：智能体干活的工作目录，工具以它为根。蜂窝里是本地目录，可直接读写本机文件；舰体部署时是服务端的用户目录。
- 线程：智能体里连续的执行上下文，一次会话的全过程都发生在线程里。
- 子智能体：智能体在任务中临时派生的工作单元，任务结束即回收，不是独立智能体。

线程内部按两级计量：用户每发一条消息记 1 个用户轮次；模型每调一次 API、执行一批工具或给出最终回复，记 1 个模型轮次。一个用户轮次里往往有很多个模型轮次，工具循环就发生在这里。

## 它怎么干活

1. 目标进入线程。system prompt 在首次确定后冻结，长期记忆以索引形式注入一次，之后不再改动，以保住模型的提示词缓存。
2. orchestrator 组装上下文，发起模型调用。
3. 模型返回工具调用时，运行时解析参数、按需请求审批、执行工具，把裁剪后的结果喂回模型，进入下一轮循环。文件、命令、浏览器、桌面控制、网页抓取、外部渠道，全部走这一条治理链路。
4. 全程以流式事件对外发布。桌面端、网页端都只是这些事件的投影，断线后靠快照和补拉恢复。
5. 上下文快满时，先对更旧的可重读工具结果做本地微压缩，还不够再生成交接摘要、重建历史。长会话因此可以一直工作下去。
6. 任务完成或用户停止后，线程状态落库，重新打开都能原样恢复。

## 形态与定位

wunder 的四个形态各有明确分工：

- **蜂窝（desktop）——本地 AI 工作台**：wunder 的桌面版，也是主推的应用。个人用户下载安装即用，本地运行，可直接操作本机文件、窗口与浏览器。
- **蜂巢（web）——云端 AI 工作台**：随舰体（server）提供的网页端，浏览器访问，供多人使用，能力与蜂窝同源。
- **舵机（cli）——手工本地操作入口**：在终端里手工操作、脚本化、自动化场景使用，TUI 交互，支持 JSONL 输出。
- **舰体（server）——用户与智能体管理平台**：需要多用户、多租户、组织治理时才部署。管理用户与智能体配置、构建与发布智能体应用、接入渠道，内置工具链、知识库和长期记忆，PostgreSQL 存储，Docker 部署。

各形态共享同一套引擎（wunder-runtime）：线程、工具、存储抽象、实时事件和权限语义是同一份代码，差异只在接入层。蜂窝（desktop）和舵机（cli）不依赖舰体。

## 设计上的几条硬规则

- 对开发者来说一切都是接口，对大模型来说一切皆工具。
- 线程 system prompt 一旦确定就冻结；长期记忆只在初始化时注入一次，中途不改写。
- 前端不是状态的真相源。后端发事件流，前端消费投影；乐观更新的部分最终要被事件回压校正。
- 所有外部能力都是工具，走统一的审批、超时、预算和结果裁剪，不靠提示词自觉。
- 舰体用 PostgreSQL，蜂窝用 SQLite，共享同一个存储抽象。
- 单写者原则：一个事件目标只有一条发布路径，一个线程同一时刻只有一个执行者。

## 能力概况

- 单智能体 + 子智能体：一个用户对应唯一智能体实例，复杂任务由它临时派生子智能体并行推进，结果回传后回收
- 文件与工作区：文件树、预览编辑与「引用到聊天」都在工作台左栏工作目录区完成；蜂窝直接操作本地文件，舰体场景下通过网页端上传下载
- 工具链：文件、命令、浏览器、桌面控制、网页搜索与抓取、LSP、PTC 等，MCP 与 Skills 可扩展
- 定时任务、网关与多渠道接入（飞书、微信、QQ、Telegram 等）
- 长会话：上下文压缩、长期记忆、额度与用量计量
- 知识库与向量检索
