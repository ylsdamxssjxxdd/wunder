# 版本日志

## 版本约定

- 版本号采用语义化版本：`MAJOR.MINOR.PATCH`。
- `MAJOR`：不兼容变更；`MINOR`：向后兼容的新功能；`PATCH`：向后兼容的问题修复。
- 在 `0.x.y` 阶段仍属原型期，功能与接口可能发生调整，不承诺跨小版本完全兼容。
- 预发布版本使用 `-alpha.N`、`-beta.N`、`-rc.N` 后缀；正式版不带后缀。
- 发布记录按时间倒序维护（最新版本在上），每个版本至少包含：发布日期、版本说明、核心能力变化。

## 0.4.3（2026-09-24）
wunder 0.4.3 星辰陨落

- 桌面发布 CI 统一为三个原生 Slint 程序：Windows 7 32 位、Ubuntu 18.04 x86_64 与 ARM64（AppImage）。
- 新增兼容老浏览器的单文件 3D 网页制作技能（内置 Three.js 运行时）。
- 运行时新增空输出/仅思考/截断参数的循环保护：默认思考预算降至 2048，连续无效输出共享一次关闭思考恢复，再次无效以 LLM_OUTPUT_LOOP 结束，线程 system prompt 保持冻结。
- 聊天输入区思考等级图标按档位填充；管理端吞吐测试口径统一（整体生成速度不含预处理）。
