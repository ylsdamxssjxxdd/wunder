## 修复前对照

对照基线标识：`9a537875c71988232b1fc54a7a7abba0875255bf`。仓库外源副本保留当时其他模块的工作树内容，只把 `services/llm.rs`、`orchestrator/llm.rs` 还原为该基线版本；新增真实入口测试没有复制被测实现。

- 暂时故障：旧流式入口第二次请求变成非流式，类型/模式断言失败；修复后保持流式并先退避。
- 工具失败后暂时故障：已配对的失败观察仍在，旧后继发生隐藏非流式降级；修复后原观察与调用身份不变。
- 截断工具流：旧适配器把 EOF 当成功，后继进入空输出补救而改写请求消息；修复后同消息重试，不生成目标文件。直接 `LlmClient` 另覆盖 partial 文本、tool arguments 和 usage。
- 鉴权拒绝：旧入口返回 `INTERNAL_ERROR`，修复后返回不可自动重试的 `LLM_REQUEST_REJECTED`；原代码的原样重试判定在模型中对应第 3 条路径。该旧入口回归先在错误码断言失败，没有把请求计数断言冒称为已执行。
- 命令超时：同一真实命令回归加入旧命令模块副本，真实超时后 `retryable` 为 true，断言失败；修复后文件仅写入一次、结果明确未知且要求核对。测试不执行危险的第二次重放；模型第 2 条重复副作用路径是环境按建议重试的推论。

复用构建缓存的中间尝试没有重新编译而误命中另一份测试产物，不计为对照证据。已核对随后日志确实重新编译外部旧源并复现，返回工作树后使源失效、重新编译并完成最终回归。原始日志、完整 TLC 状态及源副本只留仓库外。

## 同日续验：协议错误与 UTF-8 分块

本节采用同日继续修改后的结果，不覆盖首轮失败记录。首先只新增入口回归并实际编译，`services::llm::failure_tests` 为 **4 通过、4 失败**；随后修复共享适配器与外层恢复，不修改前端来掩盖协议错误。

| 新模型编号 | 真实入口与修复前观察 | 修复后验收 |
| --- | --- | --- |
| ProviderProtocol 1 | `malformed_stream_events_cannot_be_hidden_by_a_done_marker`：逐字节 HTTP 中无效 UTF-8 被有损替换，后继 DONE 仍成功；基线循环在此先失败，损坏 JSON 旧行为另由源码读取确认 | 无效 UTF-8 与损坏 JSON 两种输入均报错；真实引擎收到损坏 JSON 后同消息退避重试 |
| ProviderProtocol 2 | `successful_http_status_never_hides_provider_failures`：HTTP 200 的鉴权错误正文被接受为空成功，第一项即失败；其余封装不冒称逐项完成旧版断言 | 非流式与 SSE 分别覆盖嵌套错误、顶层 code、失败状态缺失 detail、response.failed 和错误与工具提议并存，均拒绝 |
| ProviderProtocol 3 | `null_error_fields_do_not_reject_completed_responses`：正常完成的 SSE 返回 `LLM stream payload failed: null` | 同一正常 Responses 正文/SSE 均保留 `completed` |
| ProviderProtocol 4 | `permanent_api_failure_settles_and_next_turn_reuses_the_thread`：保留修复前测试二进制再次运行，HTTP 200 鉴权错误被外层误报为 `CONTEXT_WINDOW_EXCEEDED`；旧入口先在非流式场景失败，SSE 的文字误分类另有源码依据 | 流式/非流式永久拒绝只请求一次，返回 `LLM_REQUEST_REJECTED`；失败结清后同线程下一轮成功 |
| ProviderProtocol 5 | `fragmented_utf8_preserves_content_reasoning_and_tool_arguments`：真实 HTTP 每字节分块，`示例🙂` 实际变为替代字符，正文断言失败；不把未执行到的后续断言称作旧版实证 | 正文、思考、回调与工具参数均精确相等；解码器测试遍历每个二分边界和逐字节输入，未完成缓存至多 3 字节 |

新增 `unavailable_payload_exhaustion_never_reenters_context_compaction` 实际等待六次退避耗尽；即使 `server_error` 的正文含上下文超限字样，也不得开始压缩重试；原请求消息保持一致、线程失败结清且下一轮可继续。该外层边界只有真实回归，未扩称为新模型已证明的活性。参数错误仍兼容正文说明上下文超限的旧供应方封装，相关类型分类测试保留。
