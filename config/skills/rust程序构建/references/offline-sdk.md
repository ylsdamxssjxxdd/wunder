# Offline SDK contract

`RUST_BUILDER_ROOT` points to the directory containing `win7/`, `kylin-arm/`, and `kylin-x86/`. The skill references these packages; it does not embed them.

For `win7`, use the x86_64 GNU nightly host, MinGW32/64, CMake, NASM, Rust source, and Cargo vendor/home. Build `i686-win7-windows-gnu`; keep target caches and explicitly select the i686 linker.

For Linux amd64（包括 Kylin x86），使用 `kylin-x86/offline/linux-amd64-ubuntu18`；ARM64 使用 `kylin-arm/offline/linux-arm64-ubuntu18`。 Validate ELF machine and `GLIBC_` symbols (maximum 2.27). Keep sysroot flags scoped to the target wrapper.

Every imported profile should contain `manifest.json` and `SHA256SUMS` generated by `scripts/sdk_manifest.py`. Verify hashes before a build; never download missing files automatically.
