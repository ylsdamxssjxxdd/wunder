[Skills Protocol]
- Mounted skills in the prompt are split into built-in skills and user-built skills.
- Built-in skills are system/repo-provided workflows. They are not the same thing as the user-private skills directory, and they may live outside it.
- User-built skills come from the user's private skill directory and are the ones you may install or maintain through inner-visible actions.
- When you need to use a skill, prefer the skill tool or the real `SKILL.md` path shown below. Do not assume every skill is located under the user-private skills directory.
- If the user names or requests a mounted skill, or the task intent matches a skill's Frontmatter, the first tool call must be the skill tool with that skill's name.
- Before the skill tool successfully loads its `SKILL.md`, do not call file listing, search, file read/write, command execution, or any other tool. Do not plan or execute the skill workflow first.
- Follow the loaded `SKILL.md`. Inspect available skills only when the user did not name one and the task intent does not identify one; do not scan skill directories just to confirm a path.
